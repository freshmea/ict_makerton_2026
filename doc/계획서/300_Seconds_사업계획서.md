### 소개

**개발 배경과 목적.** 아이가 스스로 목표를 고르고 자기 속도로 읽고 생각하며 문제를 풀 수 있는 시간을 충분히 보장한다. AI는 아이를 기억하되 학습 순서나 속도를 이끌지 않고, 요청받거나 사전에 합의한 도움이 필요한 순간에만 짧게 지원하는 동반자를 지향한다. 대화량보다 아이가 혼자 생각하고 학습을 이어가는 경험을 우선한다.

**제품·서비스 개요.** 마이크·스피커·카메라·네오픽셀·관절형 조명을 갖춘 책상 위 장치다. 기본은 조용한 학습 모드이며, 아이가 선택한 교재·목표·진도를 유지한다. 기억한 학습 이력과 선호는 도움 요청 시 설명을 맞추는 데 활용한다. 컨디션 질문·휴식·계획 변경도 아이의 요청이나 합의한 시점에 제안하고 아이가 선택한다.

**핵심 제품 경험.** 아이가 말없이 문제를 푸는 동안에는 말을 걸거나 손을 흔들지 않는다. “힌트만 줘”라고 요청하면 필요한 힌트 하나를 제공하고 다시 기다린다. “내가 해볼게”, “잠깐 기다려”라고 하면 즉시 멈추며, 다음 문제나 정답을 자동으로 이어 말하지 않는다. 지난 학습은 아이가 이어보기를 선택했을 때 불러온다.

**개입 원칙.** 기본 동작은 조용히 기다리기다. 도움 요청에는 힌트부터 한 번 제공하고 다시 생각 시간을 준다. 대기 시간과 알림 시점은 아이·보호자가 설정하며, 침묵을 실패나 도움 요청으로 간주하지 않는다. 사전 합의한 알림에도 반응이 없으면 반복하지 않고 기다린다. 정답·다음 문제·계획 변경은 자동으로 진행하지 않는다.

**아이를 알아가는 기억과 개인화.** ‘아이의 모든 것을 이해한다’는 비전을, 아이가 원할 때 적절히 도울 정보를 쌓고 확인하며 갱신하는 구조로 구체화한다. 성향·성격은 고정된 꼬리표 대신 선호하는 상호작용과 상황별 반응으로 기록한다. 집중력·지속력·현재 한계는 과제별 학습 지속 시간·도움 요청·휴식 기록으로 살펴보고, 심리상태·컨디션은 아이가 직접 표현한 내용과 확인 질문을 우선한다. 영상이나 목소리만으로 성격·심리상태를 확정하거나 진단하지 않는다.

현재 대화의 임시 문맥과 다음 세션에 남길 장기 기억을 구분한다. 이름 같은 명시적 정보는 정확히 유지하고, 오래된 상태나 추정은 다시 확인한다. 다음 학습에 필요한 요약과 이벤트를 중심으로 저장하며, 아이·보호자가 저장 범위를 확인·수정·삭제할 수 있도록 설계한다. 원본 음성·영상 전체를 무기한 보관하는 전제를 두지 않는다.

**말하면서 듣는 대화 설계.** 아이가 요청해 대화가 시작된 경우 양방향 대화와 인터럽트를 지원한다. 독백·소리 내어 읽기·생각 중 침묵은 대화 요청과 구분한다. 아래는 구현 요구사항이며 아직 동작을 검증하지 않았다.

**구현 구조(제안).** 기본 상태는 자율학습 대기다. 호출·도움 버튼·진행 중인 대화의 응답·사전 합의한 알림 조건을 입력받아 개입 판단을 먼저 수행한다. 요청이나 합의한 개입 조건이 충족되지 않으면 대화 생성·음성 출력·제스처를 실행하지 않고, 카메라의 단일 상태나 침묵만으로 개입하지 않는다. 도움이 허용되면 관련 기억을 검색해 짧은 힌트·설명을 제공한 뒤 대기로 돌아간다. 설명 중에는 새 발화를 듣고, 중단 요청 시 재생과 이전 응답을 취소한다. 말끝을 판단하는 대기와 아이가 문제를 생각하는 학습 대기를 구분한다. 제어 보드는 고정 독서 조명·필요 시 상태 표시·관절 동작을 담당한다. 연결·기억 조회 실패 시에도 혼자 공부하는 흐름을 유지하고 필요한 안내만 제공한다. 서비스·모델·보드·통신 방식은 시험 후 확정한다.

네오픽셀·LCD는 학습을 방해하지 않는 밝기로 유지한다. 조명은 아이가 선택한 위치·밝기를 기본으로 고정하고, 요청했을 때만 특정 문제를 강조한다. 손 흔들기·음성 알림은 합의한 조건에서 한 번만 제공하고 중지·해제를 허용한다. 채택한 폴드 윙 버디에는 발사체를 사용하지 않는다. 스마트폰 거치·충전 기능은 별도 검토한다.

**사용 흐름.** 아이가 교재·목표와 알림 여부 선택 → 자기 속도로 읽고 생각하며 풀이(AI는 조용히 대기) → 필요할 때 도움 요청 → 요청 범위의 힌트·설명·조명 지원 → 아이가 다시 혼자 생각하고 풀이(AI는 대기) → 원할 때 추가 요청·휴식·종료 → 아이가 확인한 학습 요약 저장. 도움이 필요하지 않으면 처음부터 끝까지 대화 없이 학습할 수 있고, 다음 세션의 지난 학습 회상도 아이가 선택한다.

**고객 제공 혜택.** 아이는 주도권과 충분한 생각 시간을 유지하면서 필요한 도움만 받을 수 있다. 보호자·교사는 아이가 공유하기로 한 진도·도움 요약을 참고한다. 조용히 학습을 유지한 시간과 불필요한 개입을 줄이는 경험을 검증하며, 교육·심리 효과가 입증된 것은 아니다.

**사양·가격.** 마이크·스피커·카메라·네오픽셀·서보를 포함하는 탁상형 장치를 우선 검토한다. 크기·재질·전원 정격·부품 수량은 미정이다. 기존 기기 99,000원 가설은 변경된 음성 입출력·연산 비용을 반영해 재검토한다. 대화 처리·기억 저장·통신 운영비와 지불 의사를 확인한 뒤 기기 가격·구독 조건을 결정한다.

각 대표 시나리오는 3회 이상 반복하고 발화 중단 지연과 새 응답 시작 지연을 따로 기록한다. 통신·영상 지연과 대화 지연도 구분한다. 대화 지연뿐 아니라 불필요한 개입률·반복 알림·도움 후 대기 복귀도 기록한다. 요청이 없는 시나리오에서는 침묵을 유지하는 것을 정상 성공으로 판정한다.

**사용자 검증.** 아이가 혼자 생각할 시간이 충분했는지, 원치 않는 말·빛·동작이 있었는지, 힌트 후 스스로 풀이를 이어갔는지 확인한다. 요청·중단·기억 회상의 통제감과 보호자의 기록·요약 수용성을 조사한다. 생각 시간·불필요한 개입 횟수·도움 요청·자율 풀이 재개를 관찰하되 소규모 결과를 교육·심리 효과의 확증으로 확대하지 않는다.

**모바일 운영(확장 제안).** 학부모는 연결된 자녀, 관리자는 권한이 있는 학생의 현재 상태·학습 진도·도움 내용·다음 목표를 조회한다. 상태 변화·알람의 유형·빈도·대상과 공유할 요약 범위를 설정한다. 조용히 생각하거나 소리 내어 읽는 상태를 이상·미집중으로 알리지 않으며 모바일 알림이 아이에게 반복 재촉으로 돌아오지 않도록 합의한 조건만 사용한다. 아이와 나눈 모든 대화를 자동 공개하는 대신 학습 지원에 필요한 요약을 제공하는 안이다. 원본 음성·영상 열람은 별도 범위로 검토하고 전달 수단·서버·보관 기간은 미정으로 둔다.
