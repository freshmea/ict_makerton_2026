### 소개

**개발 배경과 목적.** 혼자 공부하는 아이에게 필요한 것은 계획과 알림뿐 아니라, 자신의 이름과 지난 학습을 기억하고 오늘의 기분과 속도에 맞춰 함께 진행해 주는 상대라는 문제 가설에서 출발한다. 아이 한 명에게 지속적으로 관심을 기울이는 맞춤형 과외선생이자 학습 동반자를 지향한다. 모든 과목을 완벽하게 가르치는 능력보다, 아이의 이야기를 듣고 이해를 확인하며 학습을 이어가는 관계와 대화 경험을 우선한다.

**제품·서비스 개요.** 책상 위 로봇 또는 일상적인 오브제에 마이크·스피커·카메라·네오픽셀과 서보 구동부를 결합한다. 아이의 이름, 학습 진척도, 관심사, 선호하는 설명 방식, 반복되는 어려움과 휴식 패턴을 누적해 다음 대화와 학습 계획에 활용한다. 아이가 느끼는 피로·기분·컨디션을 묻고, 동의한 기록과 관찰 내용을 함께 참고해 설명 길이·학습 분량·격려 방식·휴식 시점을 조정하는 것을 목표로 한다. 기존 종이책·문제집과 함께 사용할 수 있도록 설계한다.

**핵심 제품 경험.** “지난번에 어려워했던 문제부터 같이 해볼까?”라고 먼저 연결하고, 설명 중 아이가 “그건 알아, 다른 방법으로 해줘”라고 말하면 즉시 듣고 설명을 바꾼다. 풀이가 막히면 정답만 제시하기보다 질문·힌트·공감으로 함께 진행하고, 세션이 끝나면 다음 만남에 이어갈 내용을 기억한다. 대화 빈도와 목소리·음량은 조절할 수 있으며 조용히 함께 공부하는 모드도 제공하는 안이다.

**아이를 알아가는 기억과 개인화.** ‘아이의 모든 것을 이해한다’는 비전을, 학습 지원에 필요한 정보를 쌓고 확인하며 갱신하는 구조로 구체화한다. 성향·성격은 고정된 꼬리표 대신 선호하는 상호작용과 상황별 반응으로 기록한다. 집중력·지속력·현재 한계는 과제별 학습 지속 시간·도움 요청·휴식 기록으로 살펴보고, 심리상태·컨디션은 아이가 직접 표현한 내용과 확인 질문을 우선한다. 영상이나 목소리만으로 성격·심리상태를 확정하거나 진단하지 않는다.

현재 대화의 임시 문맥과 다음 세션에 남길 장기 기억을 구분한다. 이름 같은 명시적 정보는 정확히 유지하고, 오래된 상태나 추정은 다시 확인한다. 다음 학습에 필요한 요약과 이벤트를 중심으로 저장하며, 아이·보호자가 저장 범위를 확인·수정·삭제할 수 있도록 설계한다. 원본 음성·영상 전체를 무기한 보관하는 전제를 두지 않는다.

**말하면서 듣는 대화 설계.** 단순히 음성 입력 후 답을 재생하는 교대식 흐름을 넘어, 발화 중에도 입력을 처리하는 양방향 대화를 목표로 한다. 다음 항목은 구현 요구사항이며 아직 동작을 검증한 기능이 아니다.

**구현 구조(제안).** 마이크 연속 입력·발화/종료 판단 ↔ 대화 처리·기억 검색 ↔ 스트리밍 음성 출력을 연결한다. 출력 중 새 발화를 감지하면 현재 재생과 생성 중인 이전 응답을 취소하고, 끼어든 내용을 포함해 다음 응답을 만든다. 카메라·학습 활동·컨디션 입력은 보조 문맥이며, 제어 보드는 네오픽셀·서보·피드백 모듈을 담당한다. 대화가 끊기거나 기록을 불러오지 못하면 아이에게 상황을 알리고 재시도·간단한 학습 모드로 전환하는 안이다. 음성 처리 서비스·모델·보드·통신 방식은 지연·비용·입출력 동시 처리 시험 후 확정한다.

네오픽셀은 듣기·사고·발화·휴식 상태를 구분하고 화면 문구도 함께 표시한다. 서보 제스처는 끄덕임·격려를 표현하며, 연질 발사체는 별도 표적을 향한 선택형 반응으로 둔다. 물리 반응이 대화를 가리지 않도록 음량·빈도·사용 여부를 조절한다. 스마트폰 거치·충전기 형태는 외형 선택지이며 충전 기능은 별도 검토한다.

**사용 흐름.** 아이 확인·지난 학습 회상 → 오늘의 컨디션과 목표 대화 → 함께 학습·질문·힌트 → 발화 중 끼어들기와 설명 수정 → 필요 시 분량·휴식 조정 → 진도·대화 요약·다음 목표 저장 → 다음 세션에서 이어가기.

**고객 제공 혜택.** 아이는 자신을 기억하고 반응해 주는 상대와 학습을 이어가며, 학부모는 단순 착석 시간 외에 어떤 도움이 필요했고 어떻게 진행했는지 확인할 수 있다. 교사·관리자는 누적 학습 요약을 바탕으로 지도한다. 이 관계 경험과 지원 효과는 사용자 체험을 통해 검증할 목표이며, 교육 성과나 심리 개선 효과를 입증한 것은 아니다.

**사양·가격.** 마이크·스피커·카메라·네오픽셀·서보를 포함하는 탁상형 장치를 우선 검토한다. 크기·재질·전원 정격·부품 수량은 미정이다. 기존 기기 99,000원 가설은 변경된 음성 입출력·연산 비용을 반영해 재검토한다. 대화 처리·기억 저장·통신 운영비와 지불 의사를 확인한 뒤 기기 가격·구독 조건을 결정한다.

### 산출물 및 개발단계

**현재 단계.** 아이디어 기획·기능 구체화 단계이며, 이번 개정에서 대화·기억·개인화 중심으로 우선순위를 조정했다. 최종 시스템의 동시 듣기·말하기, 인터럽트, 장기 기억, 학습 효과는 아직 검증하지 않았다. 기존 담당 역할을 유지하면서 음성 대화·기억·제어·모바일의 세부 담당은 팀에서 확정한다.

**보드·환경.** 기존 검토 후보인 ESP32-cam, pico2w, Raspberry Pi, Jetson Nano 등은 영상 입력·장치 제어·연산 역할에 맞춰 검토한다. 마이크·스피커 동시 동작, 재생음 재유입 처리, 네트워크·대화 응답 지연, 비용을 시험한 뒤 연산 장치와 음성 처리 구성을 선택한다. 후보 기재는 해당 보드만으로 모든 대화 기능이 구현됨을 의미하지 않는다.

각 대표 시나리오는 3회 이상 반복하고 발화 중단 지연과 새 응답 시작 지연을 따로 기록한다. 통신·영상 지연과 대화 지연도 구분한다. 단순히 대화가 이어졌다는 사실만으로 자연스러운 동시 대화를 달성했다고 판단하지 않는다.

**사용자 검증.** 아이가 편하게 끼어들 수 있는지, 자신의 말이 반영되었다고 느끼는지, 지난 학습을 기억하는 경험을 원하는지 관찰한다. 보호자에게는 개인화의 유용성, 기록 범위, 요약의 적절성과 지불 의사를 확인한다. 1주 체험에서 참여·도움 요청·학습 복귀 기록을 비교하되 소규모 결과를 교육·심리 효과의 확증으로 확대하지 않는다.

**모바일 운영(확장 제안).** 학부모는 연결된 자녀, 관리자는 권한이 있는 학생의 현재 상태·학습 진도·도움 내용·다음 목표를 조회한다. 상태 변화·알람의 유형·빈도·대상과 공유할 요약 범위를 설정한다. 아이와 나눈 모든 대화를 자동 공개하는 대신 학습 지원에 필요한 요약을 제공하는 안이다. 원본 음성·영상 열람은 별도 범위로 검토하고 전달 수단·서버·보관 기간은 미정으로 둔다.
