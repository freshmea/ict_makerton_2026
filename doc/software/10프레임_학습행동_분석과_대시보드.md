# 책상 앞의 10초: JEV 두 카메라 20장 / GPT 10장 분석

2026-10-24 KST. `책상 앞의 10초`의 JEV 기능을 얼굴·학습 공간 두 카메라의 총 20장 분석으로 변경했다. 서비스는 버튼 요청을 기다리며 자동 분석하지 않는다. 아래 실제 응답·비용 표는 변경 전 한 카메라 10장으로 수행한 검증 기록이다.

## JEV 두 카메라 분석

- `JEV · 20장 분석`: 기본은 **카메라 1 / SENSOR 0 = 얼굴**, **카메라 2 / SENSOR 1 = 학습 공간(손·책상·학습 자료)**이다. `JEV 카메라 배치`에서 두 역할을 맞바꿀 수 있다. 실제 카메라의 방향은 사용자가 각 영역을 향하도록 맞춘다.
- 1초 간격 10회에 걸쳐 매회 두 카메라의 최신 미리보기를 한 쌍으로 읽는다. 각 10장씩 총 20장을 한 번의 무료 JEV 요청으로 전송한다. 첫 쌍이 0초, 마지막 쌍은 약 9초이며 하드웨어 동기 촬영을 의미하지 않는다.
- 각 이미지 참조에 `sensor_id`, `camera_role`(`face`/`study_area`), `sample`(1~10), 경과 시간을 함께 보낸다. 같은 시점의 얼굴과 책상 증거를 결합해 15개 행동·집중·시선·자리 상태를 판단하도록 지시한다. 얼굴 표정만으로 내적 집중 상태를 추정하지 않는다.
- 두 대 모두 최신 상태이고 같은 카메라 실행 세대여야 한다. 한쪽 사진이 갱신되지 않거나 수집 실패·취소·재시작이 발생하면 20장 미만으로 전송하지 않는다. 화면 진행률·결과 이미지 수는 JEV 20장, GPT 10장으로 구분한다.
- `POST /api/study/analyze`의 기존 `{ "provider": "jev", "camera": 0 }`에서 `camera`는 **얼굴 카메라 sensor ID**다. 나머지 센서는 학습 공간이다. GPT의 `camera`는 단일 분석 카메라다.
- `GPT · 10장 분석`은 기존 방식과 테스트 예산을 유지한다. JEV 무료 대기 상태와 유료 자동 전환 금지도 유지한다. 새 20장 요청의 실제 JEV 응답은 무료 한도 해제 전에는 검증할 수 없다.

### 변경 검증

Nano의 Python 3.8에서 관찰·공급자·수집 검사 63개와 대시보드 요청 검사 7개, 총 **70개가 통과**했다. 모의 응답 브라우저 검사에서는 390px·1280px 화면, 20장 진행률과 분석 중 표시, 카메라 역할 전환, 취소, 15개 결과, GPT 10장 동작을 확인했다. 실제 배포 화면에서도 `JEV · 20장 분석`, 기본 카메라 배치, 모바일 가로 넘침 없음, 기존 무료 한도 대기를 확인했다.

실제 수집 전용 점검은 서비스와 같은 `studyobserver:boarddash` 권한으로 실행했다. **9.035초 동안 SENSOR 0에서 10장, SENSOR 1에서 10장, 총 20장**을 수집했고 2·4·…·20장 진행률과 20개 이미지 참조를 확인했다. 구성한 JSON은 513,229바이트였으며 전송하지 않았다. 원본 사진은 저장하지 않고 메타데이터만 남겼다. 이 검사는 JEV 서버의 20장 요청 수락·분석 응답을 확인한 것은 아니다.

이번 배포는 Nano의 기존 기능을 보존하고 관찰 서비스의 수집 작업·학습 분석 패널만 갱신했다. 관찰 서비스와 대시보드는 active이며, GPT 예산 장부와 JEV 한도 파일의 SHA-256이 배포 전후 일치했다. JEV 대기는 **2026-10-25 09:00 KST**까지 유지된다.

## 수집과 판단

- GPT는 최신 JPEG를 1초 간격으로 10장, JEV는 두 대에서 각 10장씩 20장을 수집하고 한 번의 API 요청으로 분석한다. 첫 수집이 0초이므로 마지막 수집은 약 9초다.
- 책상을 학습 영역으로 지정하고 시간순 이미지와 경과 시간을 함께 전달한다. 집중·책상을 향한 시선 점수는 각각 0~10이며, 관찰 근거가 부족한 점수는 null로 유지한다.
- 스마트폰, 컴퓨터·태블릿, 공부 화면 이탈, 다른 사람과 소통, 문구류, 종이·공책, 장난감·주변 물건, 시선, 자세·움직임, 자리 이탈, 음식·음료, 준비·정리, 외모·옷·액세서리, 과제 지연, 주변 환경의 **15개 행동**을 관찰됨/미관찰/판단 불가로 반환한다.
- 지속 시간과 학습 관련성을 함께 고려한다. 겹치는 항목으로 중복 감점하지 않으며, 짧은 물 마시기·스트레칭·시선 이동은 큰 감점의 근거로 단정하지 않는다. 음성이 없어 대화 내용·상대 신원·대화 목적을 추정하지 않는다. 화면 내용이나 학습 목적이 읽히지 않으면 해당 항목은 판단 불가다.
- **사용자 규칙: 자리 상태가 판단 불가이면 `is_away=true`.** 원래 관찰값은 `observed_is_away=null`, 적용 근거는 `presence_basis=user_policy_unknown_as_away`로 보존한다. `valid.is_away=false`는 영상으로 실제 부재를 확인한 값과 구분하기 위한 표시다. 사람의 재석이 명확하고 학습 행동만 불확실한 경우에는 재석을 유지한다.
- 이는 보이는 학습 행동의 추정이며 내적 집중력이나 정밀 시선 추적 측정은 아니다. 잠깐의 정지나 짧은 준비만으로 장시간의 미루기를 확정하지 않는다.

중복 실행은 거부하고, 수집 중 취소하면 전송하지 않는다. 사진이 오래되거나 카메라가 재시작되거나 수집 시각이 크게 밀리면 중단한다. 지연을 만회하려고 여러 장을 몰아서 찍거나 API를 자동 재시도하지 않는다. 사진은 메모리에서 처리하며 결과 기록에는 사진·Base64·키를 저장하지 않는다.

마지막 결과는 `is_away=true`, 집중·시선 점수 null이다. 첫 시험 당시 2번 카메라는 가까운 장비와 케이블에 가려져 있었다. API 성공과 행동 인식 정확도 검증은 구분한다. 정답을 붙인 15종 실제 행동 영상의 정확도 시험은 수행하지 않았다.

이전 텍스트·사진 시험 3회를 합친 **전체 5회 누적 추정 비용은 $0.0013735**다. [공식 Decisions 안내](https://developers.openai.com/api/docs/guides/decisions)의 `gpt-6-luna`, 표준 uncached 입력 $0.10/100만 토큰 기준이며 실제 청구액·계정 잔액을 조회한 값은 아니다. 로컬 테스트 상한은 $0.10, 요청당 $0.02 예약, 최대 5회다. 현재 **5/5회로 GPT 버튼은 로컬 제한에 도달**했다. 계정의 $10 크레딧을 소진했다는 뜻이 아니다. 장부를 자동 초기화하지 않았다.

JEV는 `jev-1.13-free`만 사용한다. 이전 무료 사용량 초과의 대기 시각은 **10월 25일 09:00 KST**이며 그 전까지 버튼을 비활성화한다. 유료 전환·한도 우회·추가 JEV 호출은 없다. 실제 JEV 이미지 응답은 아직 검증하지 못했다. 모의 응답으로 JEV 버튼의 요청 1회, 진행 표시, 15개 결과, 점수·재석 표시와 모바일 가로 넘침 없음을 확인했다. 마지막 재검사에서는 카메라 준비 조건으로 버튼이 비활성화되어 실행하지 못했고, 추가 검증은 사용자 요청으로 종료했다.

Nano에서 공급자 38개, 10프레임·정책 17개, 대시보드 11개로 **66개 검사 통과**. 실제 2장 수집 후 취소했을 때 API 장부가 3회로 유지되는 것도 확인했다. CSRF 누락·다른 Origin은 403, 잘못된 카메라 번호는 422다. 마지막 실제 결과를 모바일 390px와 데스크톱에서 확인했고 콘솔 오류는 없었다.

카메라의 Argus 연결 끊김이 시험 중 재발해 기존 `720p30` 프로필 재적용으로 복구 후 촬영했다. 이 분석 기능이 카메라 드라이버의 간헐적 연결 문제를 해결한 것은 아니다. 다음 실물 시험 전 카메라 준비 상태와 책상·학습자가 함께 보이는 화각을 확인해야 한다.

## 설치·키·상태

- 화면: `http://192.168.184.76:8000/`, 상태 `GET /api/study`, 실행 `POST /api/study/analyze`, 취소 `POST /api/study/cancel`. POST에는 기존 세션 CSRF 토큰이 필요하다.
- [분석 모듈](../../tools/jetson/study_window.py), [별도 작업 서비스](../../tools/jetson/study_observer_service.py), [설치 스크립트](../../tools/jetson/install-study-observer.sh), [대시보드 연동](../../apps/device-dashboard/observer_client.py).
- `300seconds-observer.service`는 전용 `studyobserver` 계정으로 실행한다. 대시보드·카메라 자식 프로세스에는 API 키를 전달하지 않는다. 제한된 Unix 소켓 요청만 받는다.
- 원래 키 위치는 `/etc/300seconds/ai.env`의 `OPENAI_API_KEY`, `/etc/300seconds/jev-observer.env`의 `OPENCODE_API_KEY`다. 설치 스크립트가 두 키만 `/etc/300seconds/study-observer.env`(root,0600)로 반영한다. 키 변경 후 설치 스크립트를 다시 실행해야 한다. 키는 브라우저나 PC로 복사하지 않는다.
- 현재 장부는 `/var/lib/300seconds-observer/openai-budget.json`이다. 기존 `/var/lib/300seconds/openai-observer-budget.json`의 첫 3회를 보존해 한 번 이관했으며 새 경로가 현재 CLI와 대시보드의 공통 장부다. 이전 파일은 보존본이다.

```bash
# 분석 호출 없이 서비스 상태만 확인
sudo systemctl status 300seconds-observer 300seconds-dashboard
```
