## 수행과 결과

| 시험 | 실제 결과 |
| --- | --- |
| RP2350 release 빌드 | 통과 |
| 펄스 계산·입력 검사 lib 시험 | 2개 통과, 실제 장치 시험 대체 아님 |
| host 인자 검사 시험 | 2개 통과 |
| UF2 파일 검사 | family·플래시 주소·블록·해시 확인 |
| 업로드 | E: label RP2350·INFO_UF2 Board-ID 확인 후 UF2 복사 |
| 실제 실행 | BOOTSEL 드라이브 사라짐, COM7 등장, Status 정상 |
| 첫 I2C 스캔 | count0. 이후 사용자 보고: PCA VCC 선 제거로 보드 소등 |
| 배선 수정 안내 | 제거 대상은 OE 직결선만이며 VCC→물리36 전원선 유지 필요를 재안내 |
| I2C 재스캔 | 0x41 MODE1=0x11, 0x70 MODE1=0x11 확인 |
| 단회 sweep | OK ARM→servo1..6 start/end→EVENT DONE→OK STOP |
| 종료 Status | state=stopped, i2c=ok, oe_high=1 |
| 실물 관찰 | 사용자: 6개가 순서대로 움직였으나 기대한90/180도 회전폭이 안 나옴 |

0x70은 기본 ALLCALL 응답으로 해석하며 다른 물리 보드로 집계하지 않는다. 마지막 oe_high는 GPIO 출력 레지스터 값이며 실제 OE 전압이나 기계 정지 계측값이 아니다.
