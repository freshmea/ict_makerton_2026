## 데이터와 비용

관찰·자막·검토 라벨·총평은 운영 SQLite에 저장한다. 원본 사진은 관찰 DB에 넣지 않는다. 수동 Decisions의 완료 결과와 기기 반응 기록은 Nano `study-reactions/<job-id>.json`에 남긴다. 번호 MP3와 결과 안내 WAV는 캐시하며 재생 때 합성 API를 다시 호출하지 않는다. 새 문장 합성은 기존 Typecast 문자·크레딧 한도를 적용한다.

GPT-4.1 mini 연속 관찰, GPT Live, GPT Decisions는 유료 API다. Decisions의 수동 운영 제한은 UTC 하루200회·추정$1이며, 비용이 알려지지 않은 요청은 보수적인 예약액을 유지한다. 자동 재시도는 없다. 이는 계정 전체 청구 한도가 아니다. 실기20장 요청2회는 각각7,115입력 토큰·추정$0.0007115였으며 이미지·요청에 따라 달라진다. JEV 무료 경로의 한도 대기는 별도로 유지한다.

공개 Git에는 소스·음원 자산·문서·검사 로그·데모 화면·비식별 기술 요약을 포함한다. API 키·접속 암호·운영 DB·원본 카메라 사진·실제 관찰/대화가 섞인 진단 원문은 로컬에 보존한다. `.gitignore`와 공개 검증 요약을 추가했으며, 이번 신규 공유 후보에서 실제 키·암호 패턴은 검출되지 않았다.

동기화는 일반 commit/push와 Jetson의 원본 보존 후 `--ff-only`로 수행한다. 기존 stash는 지우지 않으며 강제 push·강제 초기화·대량 삭제를 사용하지 않는다. 운영 설치본·DB와 소스 checkout은 분리돼 있으므로 Git 동기화만으로 서비스를 재배포하거나 재시작하지 않는다. 최종 커밋·청결 상태·서비스 읽기 점검은 [동기화 검증 폴더](dashboard-check/2026-10-25/git-sync/)에 기록한다.

### 동기화 완료 확인

작업 스냅샷 **[`da7f585`](https://github.com/freshmea/ict_makerton_2026/commit/da7f58536792baaa8613bee0f9a586d6e77b1eea)**에199개 파일의 변경·새 산출물을 게시하고 Windows·Jetson·GitHub `main` 일치를 확인했다. Jetson은 fast-forward 후 작업 트리가 청결했다. Nano 원본54개는 tar와 stash `b961188a1c23e893ec9fd044cedc909ce3377db9`, 보호 참조 `refs/backups/jetson-pre-sync-20261024T232343Z`에 보존했다.

동기화 전후 대시보드·observer·TTS 서비스3개가 모두 active였고 PID도 같아 재시작이 없었다. 읽기 점검에서 두 카메라 정상·약29.6~29.8fps·회전180°/0°, Pico 연결·faults0, 연속 수집 enabled=true, Live idle을 확인했다. 이 완료 확인과 JSON·로그는 작업 스냅샷 다음의 **문서 검증 커밋**으로 추가하고 양쪽을 다시 fast-forward한다. 따라서 최종 HEAD는 위 기능 커밋 뒤의 문서 커밋이며 정확한 끝은 양쪽 `git rev-parse HEAD`와 `origin/main`으로 확인한다.
