# 서보 회전폭에 맞춘 펄스 범위 복원

사용자는 0~180° 명령을 주어도 약 90°만 회전한다고 보고했다. 실기 설정은 1000~2000µs였으며, 과거 [RUN-20261023-02](../../../test-results/2026-10-23/RUN-20261023-02.md)에서 사용자가 회전폭 증가와 걸림·이상음 없음을 확인한 범위는 **500~2500µs, 약 50Hz**였다. 그 시험값이 대시보드 프로필에 이관되지 않은 것이 설정 차이의 원인이었다.

`apps/device-dashboard/pico-config.json`과 Nano의 저장소·설치본을 500~2500µs로 변경했다. 다른 입력·조명·로컬 시험 설정은 보존했다. 먼저 활성 수동 제어를 Stop하고 미Arm·OE HIGH를 확인한 뒤 적용했다. 대시보드 재시작으로 새 USB 세션이 이 파일을 Configure하고, 재시작 후 실제 Pico 상태와 서보 API에서 같은 범위를 확인했다. [변경 전](before.json), [Stop](stopped.json), [설치·백업](deployment.json), [실제 읽기 검증](live-verification.json).

| 명령 각도 | 명목 펄스 폭 | 4096단계 환산값 |
| --- | --- | --- |
| 0° | 500µs | 102 |
| 90° | 1500µs | 307 |
| 180° | 2500µs | 512 |

펌웨어의 PCA prescale 121과 20ms 기준 환산식은 변경하지 않았다. 25MHz 발진기 가정의 명목 주파수는 약 50.0288Hz이며 실제 파형 주파수를 계측한 것은 아니다. 제조사 원문의 330Hz 표기를 이번 회전폭 수정에 적용하지 않았다. 500~2500µs는 이 장치의 이전 무부하 관찰값으로, 제조사가 보증한 모든 축의 물리적 180° 범위로 확대 해석하지 않는다. 축별 실제 중앙·끝점은 별도 보정 대상이다.

검증 시 Pico 연결·PCA 0x41 응답·오류 0, 미Arm·OE HIGH, 카메라·마이크 정상 상태였다. 변경 후 실제 모터 이동은 자동 실행하지 않았다. 기존 서보 제어 회귀 검사는 [servo-tests.log](servo-tests.log)에 기록한다. 펌웨어 재업로드 없이 설정으로 적용했으며, 다음 대시보드 시작·설치에서도 프로필을 사용한다.

설치 전 파일 백업은 Nano `/var/tmp/servo-pwm-range-before-20261024.json`이다. 이전 진단에서 확인한 Nano 입력 약 4.50V 및 OC 경고의 전원 안정성 문제는 이 펄스 범위 변경으로 해결한 것이 아니다.
