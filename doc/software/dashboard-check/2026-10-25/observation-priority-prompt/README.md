# 관찰 자료 탐색: 자리·얼굴·표정·집중 단서 우선 프롬프트

2026-10-25 KST. 적용 버전 `dual-observation-v5.1-presence-face-focus`.

관찰 설명을 다음 순서로 작성한다.

1. **자리:** 학습 위치의 사람 있음 / 명확한 자리비움 / 판단 보류와 근거.
2. **얼굴:** 확인됨 / 일부 가림 / 화면 밖 / 해상도·조명 등 판별 제한.
3. **표정·감정 단서:** 보이는 눈썹·눈·입·입꼬리·하품·표정의 특징과 불확실성.
4. **집중 단서:** 학습·작업 대상, 시선·고개 방향, 필기·읽기·작업물 조작 등 보이는 행동.

사람이 있으나 얼굴이 화면 밖인 경우를 자리비움으로 분류하지 않는다. 실제 감정·이해도·내적 집중도는 확정하거나 점수화하지 않는다. 다만 얼굴이 보이면 구체적인 특징을 기록하고, 감정을 확정하지 못한다는 이유로 보이는 특징까지 전부 ‘판단 보류’로 만들지 않는다. 일부 눈이 가려지면 보이는 입 모양을 설명하고 눈만 보류한다. 책 외에 전자부품·공구·조립 재료도 작업 맥락으로 설명할 수 있다.

`description`의 네 항목과 기존 `keywords`, `actions`, `uncertainty`에 저장하므로 관찰 자료 탐색·기간/키워드 검색·CSV/JSONL에 바로 반영된다. DB 이행이나 화면 필드를 추가하지 않았다. 기존 기록은 재작성하지 않으며, 새로 들어오는 관찰부터 적용된다.

## 중복 생략 보완

이전 설명에 네 항목이 모두 없으면 새 관찰을 그 기록의 중복으로 생략하지 않는다. 카메라별 최신 기록만 참조하는 원칙과 최근 기록 10개 제한을 유지한다. 같은 행동 코드여도 자리·얼굴 가시성·표정·집중 단서의 검색 키워드가 바뀌면 모델의 중복 주장보다 새 결과를 우선 보존한다. 의미상 동일한 설명의 표현만 바뀐 경우에는 기존 중복 생략을 사용한다.
