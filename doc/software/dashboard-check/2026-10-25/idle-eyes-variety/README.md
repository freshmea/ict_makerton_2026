# 반복되는 눈 표정 개선 · 2026-10-25

관찰 근거가 부족할 때 대기 표정 9종을 무작위로 고른다. 기존에 물음표 모양으로 고정되던 일반적인 물건 다루기·휴대전화·질문 키워드 반응도 호기심 표정 6종으로 나눈다. 무작위 선택은 최근 세 번과 겹치지 않는다.

20초 선택 간격, 기존 깜빡임·윙크 재생, 명확한 학습 행동·Live·버튼 피드백, 수동 우선권과 전체 정지 동작을 유지한다. 새 AI 요청이나 서보 동작은 추가하지 않았다.

- 로컬 검사 77개 통과: 자동 선택·기존 눈 재생·관찰 저장·서보 소유권.
- Nano Python 3.8 검사 28개 통과: 자동 선택·기존 눈 재생.
- `deployment.json`: 교체 전후 해시, 백업 위치, 관찰 수집·자동 눈 설정 복원.
- `live-status.json`: 배포 후 실제 Pico의 자동 선택·점등·출력 ACK와 최근 선택 이력을 읽기 전용으로 확인한 결과.
- `observed-selections.json`: 검사 중 실제로 조회한 눈 벌리기 → 오른쪽 보기의 선택 시각과 최종 이력의 20초 주기 계산.

배포 전 진행 중이던 수동 서보 제어가 종료된 뒤 대시보드 서비스를 재시작했다. 실행 코드 교체 대상은 `automatic_eyes.py` 한 파일이며 `test_automatic_eyes.py`도 Nano 저장소·설치본에 동기화했다. 기존 SQLite는 일관 백업했고 원본 관찰·분석 총평을 삭제하거나 다시 쓰지 않았다. 관찰 수집 켜짐 상태를 복원했다.

이 검증의 실제 장치 증거는 상태·출력 ACK다. 실물 LED 모양을 사용자가 관찰해 확인한 기록과는 구분한다.

긴 연속 측정은 서비스 재시작·HTTP 연결 중단으로 완료하지 못했다. 마지막 상태 조회에서는 설치 해시 일치, 자동 눈 켜짐·상시 표시·관찰 수집 켜짐, 서보 OE HIGH·pose 비활성을 확인했다. 마지막 네 선택의 간격은 약 20.1~20.4초였다. 이때 음식·음료 행동으로 상황이 바뀌어 해당 피드백인 여유로움을 유지했다. 무작위 선택의 최근 세 번 제외는 로컬·Nano의 단위/런타임 검사에서 확인했다.
