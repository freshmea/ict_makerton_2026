# 폴드 윙 버디 v6 — 치수 기반 CAD·도면

작성일: 2026-10-23. 단위: **mm**. 개정: **P0 — 배치·끼움 검토용**.

부품 문헌 치수와 SpotMicro 원본 STL/STEP를 조사해 CAD를 새로 만들었다. **전면·측면·평면도는 동일한 CAD 솔리드에서 OpenCascade 정투상/은선 제거로 생성**했다. 사진이나 AI 이미지에서 길이를 역산하지 않았다. 외관 이미지는 이 CAD의 배치 참고용이며 제작 치수의 근거는 STEP와 치수 도면이다.

- [출력 부품 목록](PARTS.md), [검사 기록](cad/validation.json), [실측 입력표](실측_입력표.md).

## 이번에 정한 외형 설계값

아래는 새 시제품의 **설계값**이다. 보유품을 실측한 결과가 아니다.

| 항목 | v6 P0 설계값 |
| --- | --- |
| 베이스 W × D × H | 640 × 200 × 100 |
| 현재 정지 자세의 전체 높이 | 337 |
| 베이스 분할 | X=-106.6667, +106.6667에서 3분할. 각 구간 약 213.3333 폭 |
| 베이스 바닥 / 벽 / 뚜껑 | 4 / 3 / 4 |
| 중앙 헤드 | 176 × 100 × 138, 전면 커버 분리 |
| 헤드 기준 위치 | 중심 X=30, Y=5, 하단 Z=100 |
| J1 Yaw 기준 축 | X=±275, Y=40, Z=130, 축 방향 Z |
| J2 Pitch 기준 축 | X=±220, Y=40, Z=315, 축 방향 Y |
| J1–J2 기준점 거리 | √(55²+185²) = 193.0025907 |
| 눈 창 | 32.8 정사각형 2개, 중심 간격 51, Z=180. **모듈 실측 후 수정** |
| 카메라 개구 | Ø10.5, 중심 X=30 / Z=219. **개구는 설계 가정** |

좌표: X는 좌우, Y는 앞뒤(앞이 음수), Z는 바닥에서 위쪽이다. 전면은 −Y에서 +Y를 본다. CAD의 서보 40 mm 수직 외형은 **배치용 예약 높이**이며 제조사에서 확인된 본체 높이라고 주장하지 않는다. 카메라 PCB 두께 1.6, 렌즈 Ø10×8, 매트릭스 표시 블록 32×32도 미실측 가정이다. 메인보드·전원·배터리의 파란 상자는 부품이 아니라 예약 공간이다.

BA-R9는 제조사 설명서의 **400(W)×73(D)×68(H)** 외형으로 배치했다. 기존 v5처럼 스피커가 베이스 거의 전폭을 차지하게 늘리지 않았다. 노브·고무 발·케이블은 실측 대상이며 전면 개방부는 최종 고정 구조가 아니다.

## SpotMicro에서 가져온 관절 원리

[원본 관절 분석](reference/joint_reference.md), [원본 파일과 해시](reference/SpotMicro_provenance.json)를 참조한다.

1. **서보 본체를 고정부에 고정**하고 현품에 맞는 혼으로 움직이는 부품에 토크를 전달한다.
2. **같은 축선의 반대쪽에 F625ZZ 베어링**을 두어 외팔 하중을 분담한다. 스플라인을 PLA에 직접 인쇄하는 방식으로 대체하지 않는다.
3. 원본 `L_arm_cover.stl`에서 베어링 몸체 자리 **Ø16.3×깊이 4**, 플랜지 자리 **Ø18.2×깊이 1**을 메시 좌표로 확인했다.
4. F625ZZ의 제조사 공칭은 **내경 5 / 외경 16 / 폭 5 / 플랜지 Ø18×1**이다. 0.3 mm 직경 여유는 원본 설계 선택이며 이번 출력에 그대로 맞는다는 뜻은 아니다.

v6는 기존 사용자 시안의 **수직 Yaw + 수평 Pitch**를 유지한다. 같은 평면에서 접히는 로봇 팔로 바꾼 것이 아니다. SpotMicro의 3축 다리 전체를 복사하지 않고 혼·반대편 베어링·배선 통로 원리를 참고했다. 원본 CLS 수정 STEP는 110×52.5×70 및 110×5×66 크기로 확인했으나 새 제품에 그대로 조립되는 부품으로 간주하지 않는다.

**아직 최종 모델에 없는 체결부:** 실제 혼에 맞는 어댑터, 반대편 Ø5 지지축·스페이서·이탈 방지 캡, J1 회전 캐리어와 상부 베어링 지지, 헤드와 베이스 고정점, 매트릭스 PCB 브래킷, PCB 트레이 고정점, 스피커 스트랩·폼 고정부. 이 부분을 임의로 확정한 조립용 STL로 제공하지 않았다. 현재의 원형 Yaw 부품은 배치 기준 형상이며 실제 축 결합품이 아니다.

## 먼저 출력할 것

- [서보 끼움 시험편 STL](reference/joint_test_parts/servo_fit_trial.stl): 외형 60×35×4, 개구 41.3×21.0, 4×Ø3.4, 홀 간격 49.5×10. 공급자 도면 기준의 가설을 현품으로 확인한다.
- [F625ZZ 끼움 시험편 STL](reference/joint_test_parts/F625ZZ_bearing_fit_trial.stl): 외형 94×30×6, Ø15.9/16.0/16.1/16.3 비교, 플랜지 자리 Ø18.2×깊이 1.2.
- 같은 폴더에 수정 가능한 STEP와 [기하 검사 결과](reference/joint_test_parts/verification.json)가 있다.

두 시험편을 **100%, mm 단위**로 먼저 출력한다. 끼움과 홀 간격을 확인한 뒤 큰 외장으로 진행한다. 나머지 17개 STL은 P0 형상·출력 크기 검토용이며 최종 조립품이 아니다. 베이스는 3개 트레이+3개 뚜껑으로 나누고 후면 바닥 연결판으로 잇는 구상이다. 256 mm보다 작은 경계상자는 X1 Carbon 빌드 범위 검토이며 실제 배치·서포트·출력 품질 검사까지 완료했다는 뜻은 아니다.

베어링 4개(각 축 반대편에 1개씩)의 추가 사용을 계획한다. 이는 **추가 필요 부품**이며 현재 보유 여부는 미확인이다. 금속 혼·지지축·볼트·너트·스페이서 규격과 수량도 실측 후 확정한다.

## 검증한 것과 남은 것

- 새 출력 부품 17개 모두 BREP 유효성, **단일 솔리드**, 양의 체적, 닫힌 STL, 축별 외형 256 mm 이하를 검사했다.
- 선정한 정지 자세에서 서보–뚜껑, 서보–브래킷, 손바닥–팔, 스피커–베이스 등 **14쌍의 체적 간섭이 0**임을 확인했다. 전체 부품 조합이나 회전 중 모든 간섭을 검사한 결과는 아니다.
- 공식/판매처 자료의 출처와 [치수 근거](dimensions/치수_근거와_실측항목.md)를 보관했다.
- SolidCraft MCP의 표시용 bbox와 정확한 에지 좌표의 차이를 보존했다. 제작 치수에는 CAD 원본·에지 좌표를 사용했다.
- **미검증:** 현품 치수·혼 결합·조립·고정·가동 범위·케이블 굽힘·토크·진동·전도·발열·실제 출력 수축. 큰 부품을 출력하기 전 실측 입력표와 시험편으로 인터페이스를 확정해야 한다.

## 재생성 및 파일 기준

`cad/build_v6.py`가 CAD, STL, 정투상 PDF/SVG/PNG와 CAD 렌더를 생성한다. `reference/joint_test_parts.py`는 작은 시험편을 생성한다. 외부 `parameters_override.json`은 P0에서 비활성화했다. 수정할 때 소스 형상 수치와 도면을 함께 재생성해야 하며, `parameters_used.json`만 고쳐서는 형상이 바뀌지 않는다.

이번 작업은 프로젝트 `tmp/cad-runtime`에 격리 설치한 CadQuery 2.4.0 / cadquery-ocp 7.7.2 / trimesh 4.5.3 및 기존 Python 렌더링 라이브러리를 사용했다. 사용자 CAD 앱·전역 패키지 설정을 변경하지 않았다. 재실행 예: 프로젝트 루트에서 `python doc/BOM/mechanical_v6/cad/build_v6.py`.

STEP는 mm 단위를 포함한다. STL은 파일 자체에 단위가 없으므로 슬라이서에서 mm로 가져오고 자동 크기 변경을 하지 않는다. 구판 v4/v5 시안과 기존 BOM 자료는 보존했다. 원본 SpotMicro 부품의 출처·라이선스도 [참조 폴더](reference/joint_reference.md)에 함께 보관했다.
