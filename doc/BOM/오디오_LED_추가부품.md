# 마이크·스피커·네오픽셀 추가 부품

확인일: 2026-10-23 (한국 시간). 사용자 제공 사진 3장으로 식별했다. 실제 녹음·재생·점등 시험은 수행하지 않았다.

## B12 — 클립형 유선 마이크

- 사진에서 검은색 클립형 마이크와 3.5mm 계열 플러그가 확인된다. 제조사·모델명은 보이지 않는다.
- 마이크 방식, 감도, 주파수 응답, 임피던스, 바이어스 전압, TRS/TRRS 및 접점 배치는 **미정**이다. 사진만으로 특정 핀마이크의 데이터시트를 적용하지 않았다.
- 마이크 자체의 데이터시트는 모델 식별 전까지 **미확보**로 기록한다. 플러그의 절연 링 수와 제품 라벨/구매 품번을 확인하면 후속 선정할 수 있다.
- [원본 사진](../../img/Lavalier_Microphone_UGREEN_USB_Audio_20261023.png)

## B13 — UGREEN USB 오디오 어댑터

- B12와 같은 사진에 있는 별도 부품이다. UGREEN 로고와 USB-A 플러그는 확인되지만 품번 및 오디오 포트 구성은 사진에서 확정할 수 없다.
- 외형이 유사한 **UGREEN 30143**의 지역 브랜드 사이트 자료를 참고용으로 저장했다. 이 제품은 헤드폰 출력과 모노 마이크 입력을 설명하지만, **보유품을 30143으로 확정한 것은 아니다**.
- [S28 참고 페이지 저장본](web/UGREEN_30143_candidate_reference.html), [원문](https://ugreen.com.tr/urun/ugreen-usb-harici-3-5mm-stereo-ses-karti-beyaz/)
- Jetson 사용 시 `lsusb`, `arecord -l`, `aplay -l`로 USB 장치와 녹음/재생 장치 인식을 확인하고, 해당 입력을 선택해 녹음한다. 이 명령은 아직 실행하지 않았다.
- 마이크는 실제 **MIC 입력**인지 확인한 포트에 연결한다. 헤드폰 전용 출력이나 TRRS 전용 단자는 플러그와 호환되지 않을 수 있으므로 현재 꽂힌 위치만으로 호환성을 판단하지 않는다.

## B14 — Britz BA-R9 SoundBar

사진의 BA-R9 SoundBar 및 Britz 표기로 모델을 식별했다. [S23 제조사 제품 페이지](web/Britz_BA-R9_official.html)와 [S24 제조사 사용설명서 JPG](manuals/Britz_BA-R9_manual.jpg)를 확보했다. 제조사에서 제공하는 문서는 JPG 형식이며 독립 PDF 데이터시트는 확보하지 못했다.

| 항목 | 제조사 사용설명서 확인값 |
| --- | --- |
| 전원 | DC 5V, USB 전원 |
| 오디오 입력 | 3.5mm 아날로그 입력 |
| 출력 | 3W × 2, 2채널 |
| 유닛 / 임피던스 | 50mm × 2 / 4Ω |
| 주파수 응답 | 100Hz–18kHz |
| 치수 | 400(W) × 73(D) × 68(H) mm |
| 조작 및 단자 | 전원, 볼륨, 헤드폰 단자, 마이크 단자 |

USB는 **전원 공급용**이다. USB 연결만으로 디지털 USB 스피커가 되는 구성이 아니다. Jetson에서 사용하려면 USB 오디오 어댑터 등의 아날로그 출력에 BA-R9의 오디오 입력 플러그를 연결하고 USB 전원을 별도로 공급한다. B13의 실제 출력 포트 및 동시 녹음/재생 가능 여부는 확인 대상이다. 전면 마이크 단자를 내장 마이크로 해석하지 않는다. 6W는 오디오 출력 표기이며 USB 입력 소비전류를 6W/5V로 확정하지 않는다.

## B15 — 5V 주소지정 LED 스트립 (네오픽셀 계열 추정)

- 사진에서 **7개 스트립**, 각 6픽셀로 보여 **총 42픽셀로 잠정 집계**했다. 검정/흰색 기판과 투명 피복이 섞여 있다. 길이, LED 밀도 및 피복의 방수 등급은 실측·라벨 확인 전까지 미정이다.
- 기판의 `+5V`, `DIN`, `DO`, `GND`와 데이터 방향 화살표를 확인했다. 입력은 DIN, 다음 스트립으로 보내는 출력은 DO이다. 사진 방향이나 전선 색으로 극성을 정하지 않는다.
- 외형 및 단자는 WS2812B/SK6812 등 여러 제품이 공유한다. **WS2812B인지, RGB/RGBW인지, IC 리비전이 무엇인지는 미정**이다. Adafruit 정품 NeoPixel 여부도 확인되지 않았다.
- [S25 WS2812B V5 데이터시트](datasheets/WS2812B_V5_reference.pdf)는 Worldsemi 문서의 Seengreat 보관본이다. **후보 IC 참고용**이며 보유 스트립의 확정 사양서가 아니다.
- [S26 Adafruit NeoPixel 가이드 PDF](manuals/Adafruit_NeoPixel_Uberguide.pdf), [S27 배선 권고](web/Adafruit_NeoPixel_best_practices.html)는 호환 계열의 일반 사용 참고자료다.

### 연결 및 전원 검토

1. 실크 표기 기준으로 안정화된 5V 전원을 `+5V/GND`에 공급한다. 배터리 7.4V나 12V를 직접 넣지 않는다. Jetson GPIO에서 LED 구동 전류를 공급하지 않는다.
2. 제어기와 LED의 GND를 공통으로 연결하고 데이터를 DIN으로 보낸다. Jetson은 3.3V 신호이므로 5V LED 입력 임계값에 맞는 로직 레벨 변환을 검토한다. 5V 신호를 Jetson 입력으로 되돌리지 않는다.
3. Adafruit 가이드는 첫 픽셀 DIN 근처의 직렬 저항 300–500Ω 및 전원 입력의 500–1000µF 커패시터(6.3V 이상)를 권고한다. 이는 일반 권고이며 현품 보드 내장 회로와 대조한다.
4. 구형 RGB 픽셀의 보수적 전원 예산인 60mA/픽셀을 가정하면 42개는 약 2.52A, 12.6W이다. **계산용 가정**이며 현품 소비전류나 정격 측정값이 아니다. IC 확인 후 밝기 제한과 실측으로 전원을 선정한다.
5. 제어 프로토콜·색상 순서를 먼저 한 픽셀/한 스트립으로 확인한다. PCA9685의 일반 PWM 서보 출력으로 이 직렬 데이터 프로토콜을 직접 대체할 수 없다. Jetson용 제어 방식 또는 별도 MCU는 아직 선정하지 않았다.
