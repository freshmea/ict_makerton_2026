# LED 매트릭스·터치 센서 추가 부품

확인일: 2026-10-23 (한국 시간). 사진 2장 기준이며 실제 점등·터치 입력 시험은 수행하지 않았다.

## B16 — MAX7219 표기 8×8 LED 매트릭스 모듈

- **수량:** 모듈 1개(8×8, 64도트).
- **사진 확인:** IC에 `MAX7219ENG`로 보이는 표기와 입력 헤더의 `VCC / GND / DIN / CS / CLK`가 있다. IC 제조사·진품 여부, LED 매트릭스 자체 품번과 발광색, 보드 리비전은 미정이다.
- **자료:** [S29 Analog Devices MAX7219/MAX7221 데이터시트](datasheets/MAX7219_MAX7221_Analog_Devices.pdf), [S30 제조사 제품 페이지](https://www.analog.com/en/products/max7219.html)(HTML 저장은 연결 종료로 실패; S29 PDF 확보).
- **용도 후보:** 300 Seconds 제품의 눈·표정·숫자·상태 표시. 단일 모듈은 8×8 해상도이며 실제 표시 방향은 시험 후 확정한다.
- [원본 사진](../../img/MAX7219_8x8_LED_Matrix_20261023.png)

### 사양과 연결 검토

MAX7219는 64개 개별 LED 또는 최대 8자리 공통 캐소드 표시기를 제어하는 직렬 입력 드라이버다. 표시 데이터 저장, 스캔 및 밝기 제어 기능이 있다. 해당 IC 자료의 전원 동작 범위는 4.0–5.5V이며 일반적인 모듈 구성은 5V를 사용한다. 이는 현품 모듈 전체의 전류 정격 보증이 아니다. RSET 저항값과 LED 사양을 확인해야 한다.

| 모듈 핀 | 역할 / 연결 검토 |
| --- | --- |
| VCC | 안정화된 5V 전원. 7.4V 배터리·12V 어댑터 직접 연결 금지 |
| GND | 전원 및 제어기의 공통 접지 |
| DIN | 직렬 데이터 입력 |
| CS | LOAD/선택 신호. 사진에는 CS로 표기 |
| CLK | 직렬 클록 입력 |

사진과 반대로 놓으면 좌우가 바뀌므로 **실크 표기**로 핀을 찾는다. MAX7219의 로직 HIGH 최소 입력은 3.5V이므로 Jetson의 3.3V 출력을 데이터시트상 보장되는 HIGH로 볼 수 없다. DIN·CLK·CS에는 적절한 3.3V→5V 레벨 변환을 검토한다. LED 구동 전류를 GPIO 신호 핀으로 공급하지 않는다.

입력 프레임은 주소/데이터를 포함한 16비트다. 초기화에서는 행 스캔, 밝기, 디코드 모드 및 셧다운 설정을 검토한다. 비트맵 표시는 no-decode 방식이 적합하며, 행·열 배치와 표시 방향은 현품에서 확인한다. 구체적인 Jetson 헤더 번호와 라이브러리는 아직 선정하지 않았다.

원문: [Analog Devices 데이터시트](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX7219-MAX7221.pdf), [제품 페이지](https://www.analog.com/en/products/max7219.html)

## B17 — 단일 키 정전식 터치 센서 모듈 6개

- **수량:** 사진에서 서로 구분되는 모듈 6개(3열 × 2행). 연결된 판 형태로 보이나 전기적으로 독립인지, 분리 전 사용이 가능한지는 기판 확인이 필요하다.
- **사진 확인:** 원형 터치 전극, 6핀 SMD IC, `IO / VCC / GND` 실크 표기를 확인했다. 각 모듈 방향이 다르므로 화면 기준 좌우 순서로 연결하지 않는다.
- **식별 상태:** TTP223 계열과 유사한 외형이지만 IC 표기가 읽히지 않는다. **TTP223-BA6로 확정하지 않았다.**
- **자료:** [S31 Tontek TTP223-BA6/TTP223N-BA6 V2.1 데이터시트](datasheets/TTP223_BA6_V2_1_Tontek_reference.pdf), [S32 제조사 제품 페이지](web/Tontek_TTP223_BA6_candidate.html). 두 자료는 후보 IC 참고자료이며 현품 보드 회로도·확정 사양서는 미확보다.
- **용도 후보:** 제품의 시작·정지·선택용 터치 버튼. PLA 외장 아래 부착할 경우 외장 두께, 전극 크기, 주변 배선과 접착 방식에 따른 감도 시험이 필요하다.
- [원본 사진](../../img/Capacitive_Touch_Modules_6pcs_20261023.png)

### 후보 IC 자료와 사용 전 확인

TTP223-BA6 계열의 IC 동작 전압은 2.0–5.5V이다. 출력은 CMOS 방식이며 설정 핀에 따라 순간 동작/토글 및 Active HIGH/LOW를 선택한다. 보유 보드의 기본 모드와 옵션 배선은 미정이다. IC의 저전력 전류 수치를 보드 전체 소비전류로 적용하지 않는다.

| 모듈 핀 | 역할 / 연결 검토 |
| --- | --- |
| VCC | 보드 품번·회로 확인 후 전원 결정. TTP223 계열로 확인되고 보드가 지원하면 3.3V 구동을 검토 |
| GND | 제어기와 공통 접지 |
| IO | 터치 결과 디지털 출력. 선택한 모드와 실제 HIGH 전압 확인 후 GPIO 입력에 연결 |

5V로 구동한 보드의 IO를 Jetson 3.3V GPIO에 바로 연결하지 않는다. 3.3V 전원에서 보드가 동작하고 출력도 호환되는지 확인하거나 적절한 레벨 변환을 사용한다. 터치 입력은 통신 주소를 가진 I2C 장치로 가정하지 않으며, 6개를 개별로 읽으려면 각각의 입력 경로가 필요하다.

후보 IC 설명서에서는 전원을 켠 뒤 약 0.5초 안정화 구간에 전극을 만지지 않도록 안내한다. 현품 확인 후 이 조건과 실제 출력 모드를 시험한다. 외장에 부착한 상태에서 감도를 확인하며 표면 금속 도료·도전성 재료의 영향도 검토한다.
