Genel Bakış

Ugreen USB Harici 3.5mm Stereo Ses Kartı, bir stereo kulaklık çıkış jakı ve bir mono mikrofon giriş jakı içerir. Arızalı ses kartını veya dizüstü / masaüstü sisteminizin hatalı 3,5 mm ses bağlantı noktasını kullanmadan ses işlevini sizin için yeniden kazandırabilir. Böylelikle arızalı bir ses kartını değiştirme maliyetinden tasarruf etmiş olursunuz.

Geniş Uyumlu – Sürücü Gerektirmez

Sürücüye gerek yok, sadece tak ve çalıştır! Windows 10 / 98SE / ME / 2000 / XP / Server 2003 / Vista / 7/8 / Linux / Mac OS X / PS4 / Google Chromebook / Windows Surface Pro 3 / Raspberry Pi ile uyumludur.

Kompakt ve Taşınabilir

Dayanıklı ABS malzemesi kullanılan bu ürün yeterince hafiftir ve küçük boyutu taşınabilirlik özelliğini arttırır.

Uyumlu Sistemler

* Windows 10, Windows 8.1/8, Windows 7, Windows Vista, Windows XP, Mac OS 8.6 ve üzeri

Not:

PS3’teki USB arabirimi ses sinyali taşımaz, bu nedenle bu USB ses adaptörü PS3 ile çalışmaz.
