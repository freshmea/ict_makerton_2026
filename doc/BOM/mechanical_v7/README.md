## 수정된 관절

1. **고정측:** 곡선 팔 끝의 Ø80 원형 코어 안에 서보를 수납한다. 케이스는 출력축 위치 차이 때문에 축선에서 한쪽으로 치우치지만 코어 밖으로 돌출하지 않는다.
2. **구동측:** 짧은 출력축의 실제 서보 혼을 앞 커버 안쪽 홈에 포획한다. 앞 커버와 뒤 베어링 커버는 코어 외곽의 브리지로 연결되어 손과 함께 회전한다.
3. **반대편 지지:** 움직이는 뒤 커버가 F625ZZ 외륜을 지지하고, 고정 코어의 동축 지지축이 내륜을 받친다. 혼과 반대편 베어링은 같은 Y축선에 있다.
4. **십자 홈:** 4갈래 홈은 움직이는 앞 커버에 들어 있다. 작은 별도 인서트가 아니라 앞 커버를 교체하는 구성이다. 중심 나사 통과 구멍은 시험값 Ø5.3이다.

원본 `O_shoulder_cls_grooved_modi.stp`의 혼 포켓은 **6갈래**, 구형 `L_arm.stl`은 **한쪽 팔형**이다. 이번 4갈래 십자는 사용자 요청을 반영한 새 시험 형상이며 원본 혼을 그대로 복제했다고 보지 않는다. 원본 단면과 SHA-256은 [재분석 자료](reference/original_joint_reaudit.md)에 보존했다.

## 원래 디자인을 살린 형상

직선 기둥을 바깥쪽으로 휘어진 스플라인 팔로 바꿨다. 머리는 둥근 페블 곡면과 검정 캡슐형 얼굴, 눈은 독립된 8×8 매트릭스 2개를 유지한다. 손은 얕은 타원형 오목 곡면과 둥근 고정 손가락, 베이스와 휴대폰 받침은 둥근 외곽으로 만들었다. 손의 확산부는 상태 LED 구상이며 가변 렌즈 구동부가 아니다.

팔의 곡선 픽셀 위치는 표시용 배치다. 현품 스트립을 평면 안에서 강제로 휘게 하는 설계로 확정하지 않았다. 픽셀 절단·점퍼 배선 또는 직선 스트립과 넓은 확산창 중에서 실물을 보고 선택해야 하며 내부 트레이·확산창 체결은 미설계다.

## 출력 전 남은 치수

우선 서보 혼·케이스를 실측해서 앞 커버와 코어의 끼움을 확인한다. [기존 실측 입력표](../mechanical_v6/실측_입력표.md)에 더해 다음 항목이 필요하다.

- CLS6336HV 현품의 출력축 오프셋, 케이스 높이, 플랜지·혼의 정확한 형상과 중심 나사.
- F625ZZ 실물 외형과 출력 끼움, 반대편 축의 재료·어깨·스페이서·이탈 방지 체결.
- J1 Yaw 베어링 캐리어·축방향 고정, 앞뒤 서비스 외장 체결 및 서보 고정 볼트 접근 경로.
- 매트릭스 보드 전체 크기·두께·체결점, 실제 부품·USB 플러그·배선 여유.

P1의 22개 STL은 분할 형상 확인용이다. 나사·인서트·베어링 유지 구조가 모두 확정된 최종 조립품은 아니다. 반대편 베어링을 넣는 구조를 만들었다는 사실과 실제 마찰·유격·하중을 시험했다는 사실을 구별한다. 전체 큰 외장 출력 전 작은 끼움 시험이 필요하다.

## 검증 범위

- 생성된 출력 부품 22개: 유효 BREP, 단일 솔리드, 양의 체적, 폐합 STL. 각 부품 경계상자는 256mm 이내다. X1 Carbon에서의 실제 출력 배치·서포트·수축은 검증하지 않았다.
- 선택한 정지 자세 간섭 검사 22쌍: 교차 체적 0. 서보 대 코어/움직이는 커버와 BA-R9 대 베이스를 검사했다. 전체 회전 범위·하중·배선 동작 시험은 하지 않았다.
- 전체 STEP 재입력: CadQuery/OpenCascade에서 47개 유효 솔리드. 원본 어셈블리의 75개 구성 항목과 가져오기 바디 집계는 다르다.
- SolidCraft MCP: 별도 분석 세션에서 저장·화면 확인했다. **손 외장 앞뒤 4개는 열린 바디 가져오기 경고가 남아 있다.** 편집용 닫힌 솔리드로 확인한 결과가 아니다. [상세 기록](reference/solidcraft/README.md).
- STL 변환 중 일부 곡면의 중복·퇴화 삼각형을 정리했고, 오른쪽 뒤 커버 메시는 대칭인 왼쪽 부품을 미러하여 폐합했다. 기록은 `validation.json`의 raw/cleanup 항목에 있다.

## 재생성과 이력

`cad/build_v7.py`가 기준 생성 코드다. `cad/model_P1.py`는 기하 블록의 보조 스냅샷이며 별도 실행 파일이 아니다. CadQuery 2.4/OCP 7.7 계열, numpy, matplotlib, trimesh, PyMuPDF가 필요하다. 이 환경은 저장소의 `tmp/cad-runtime`을 먼저 찾는다. 외부 parameters override는 비활성화했다. 수치 변경은 코드 형상·도면을 함께 재생성해야 한다.

`reference/generate_joint_detail.py`가 원본 분석과 새 시험값을 구분한 2페이지 설명도를 생성한다. 이 설명도는 실제 CAD 단면 선화를 대신하지 않으며 [STEP 단면 추출 이미지](reference/P1_core_cutaway.png)를 함께 제공한다.

지적된 v6 `FWB_DETAIL_reference_A3_page2.png` 경로도 P1으로 교체했다. 기존 외부 서보 참고도·생성기는 [v6 이력](../mechanical_v6/history/P0_external_servo)에 보존했다. v6의 전체 조립 CAD는 과거 P0이며 최신 기구 기준은 이 v7 폴더다. P1에서 폐기한 별도 Yaw 혼판은 `history/retired_separate_rotors`에 보존했으며 출력 목록에 포함하지 않는다.
