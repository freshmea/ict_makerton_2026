# v7 P1 독립 파일 QA

확인일: 2026-10-23. 원본 생성기를 실행하지 않고, 내보낸 파일을 다시 읽어 검사했다. 상세 수치·파일 SHA-256·방법과 한계는 [independent_QA.json](independent_QA.json)에 있다.

- 전체 조립 STEP는 CadQuery/OpenCascade 재입력에서 **47개 솔리드 / 47개 셸**, BREP 유효성 통과 및 모든 셸의 Closed 플래그 참으로 확인했다. STEP의 mm 단위 선언도 확인했다.
- SolidCraft에서 열린 바디로 경고된 `L/R_WRAP_HAND_FRONT/REAR` 4개의 개별 STEP는 각각 유효한 단일 솔리드 및 닫힌 셸로 재입력됐다.
- 같은 4개 STL은 각각 폐합·방향 일관성·단일 메시 검사를 통과했다. STL 체적은 해당 STEP보다 약 **0.50–0.52% 작다**. 이는 곡면 테셀레이션 근사 차이이며 출력 공차가 아니다.
- 원 검사 기록의 구성 요소 수 75와 STEP/SolidCraft 바디 수 47은 서로 다른 보고 수량이다. 이 검사에서는 수치 차이의 원인을 추정하지 않았다.

## SolidCraft 경고의 해석

SolidCraft는 오류 0, 열린 셸 경고 4건을 반환했다. CadQuery와 STL의 별도 통과가 이 경고를 해결하거나 SolidCraft 편집용 완전한 닫힌 솔리드를 보증하지 않는다. 따라서 [SolidCraft 기록](solidcraft/README.md)의 가져오기 제한을 계속 적용해야 한다.

이번 검사는 파일 읽기와 정적 기하 검증이다. 실제 출력·끼움·베어링 지지축 고정·분할 커버 체결·J1 Yaw 지지·토크 및 전 가동 범위 검증을 대신하지 않는다. 해당 값은 최종 제작 확정 전 남은 항목이다.
