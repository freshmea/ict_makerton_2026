# SpotMicro 관절 원본 재분석 및 v7 P1 수정 근거

확인일: 2026-10-23. 길이 단위 mm. 원본 파일은 변경하지 않았다.

## 수정해야 하는 구조

v6의 외부 서보와 길게 가로지르는 축 배치는 원본의 내장 서보·감싸는 연결부를 충분히 반영하지 못했다. v7 P1은 서보 몸체를 원형 고정 코어 안에 넣고, **짧은 출력축 → 실제 서보용 혼 → 혼을 잡는 움직이는 앞판 → 코어를 감싸는 연결부 → 반대편 베어링 앞/뒷판** 순서로 수정한다. 반대쪽 베어링과 서보 출력축은 한 축선에 둔다. 서보 외형 중심은 출력축과 같지 않기 때문에 케이스가 원형 코어 내부에서 한쪽으로 치우치는 것은 필요하다.

베어링 외륜은 움직이는 뒤판에, 내륜은 고정 코어의 반대편 지지축에 놓인다. 서보 케이스와 고정 코어는 고정측, 혼·앞뒤 감싸는 판·연결 브리지는 구동측이다. 축방향 체결 부품과 스페이서는 아직 확정하지 않았다.

## 원본에서 실제 확인한 형상

원본은 [Road-Balance/SpotMicroJetson](https://github.com/Road-Balance/SpotMicroJetson), 커밋 `2235c77a93e86d04dec2e03c6306ba2c06d454ce`이다. [보존된 원본 STEP/STL](../../mechanical_v6/reference/SpotMicro_parts)에 있는 형상을 CadQuery/OpenCascade와 trimesh로 단면 분석했다. 실행 파일은 `recheck_original_joint.py`, 메시 단면 점/출처 SHA-256은 `original_joint_sections.json`이다. 단면은 보간된 원본 모델 좌표이며 실물 캘리퍼 측정이 아니다.

| 파일 및 위치 | 확인한 형상과 치수 | 적용 판단 |
|---|---|---|
| `O_shoulder_cls_grooved_modi.stp` | 두 혼 포켓 중심 XZ=(16,26), (94,26), 중심 간 78.0. Y=2.3~5.0의 깊이 2.7인 **6갈래 별형 포켓**, 포켓 외형 약 28.976×32.600. 바닥까지 연결되는 축/나사 통과부 약 Ø9 | 혼을 출력물에 포획하여 회전 전달하는 방식의 직접 근거. 이 CLS 버전은 십자 4갈래와 모양이 다름 |
| `I_shoulder_cls_modi.stp` | 원형 수납부와 코어를 감싸는 굽은 탭. 전체 외형 110×52.5×70 | 서보를 한쪽 바깥에 달아 긴 허브로 연결하는 것이 아니라 내부 공간과 외부 판을 함께 사용하는 형태 |
| `L_arm.stl` | 서보를 수납하는 링크와 축 끝의 **한쪽 팔 혼 포켓** | 같은 저장소에도 혼 종류에 따른 다른 형상 버전이 존재 |
| `L_arm_cover.stl` | 축선 XZ≈(1.17473,124.92493), 방향 Y. Y40~41에 Ø18.2 플랜지 자리, Y41~45에 Ø16.3 몸체 자리, 총 깊이 5 | 반대편 베어링을 같은 축선에 지지하는 직접 근거 |

`I/O_shoulder_cls`와 구형 `L_arm`은 서로 다른 부품/버전이므로 좌표를 그대로 포개서 검증된 조립체라고 부르지 않는다. 저장소 조립 설명은 잘라낸 혼을 링크에 맞춰 접착한 뒤 혼 나사로 서보에 체결하고, 커버의 반대편 베어링을 수납한다고 설명한다. [원 조립 가이드](https://spotmicroai.readthedocs.io/en/latest/assembly/). 원 BOM에는 F625ZZ 베어링과 CLS6336HV가 있다.

## v7 P1의 설계값과 미확정값

| 항목 | P1 명목값 | 상태 |
|---|---:|---|
| 고정 원형 코어 | Ø80, Y13~67, 길이 54 | 새 설계값 |

| 서보 수납 여유 영역 | 41.3×44×21.0 | 새 설계값, 출력 끼움 시험 필요 |

| 움직이는 뒤판 | Y68~74 | 새 설계값 |
| 베어링 자리 | Ø16.3 관통공 Y68~74, Ø18.2 플랜지 홈 Y73~74. 실제 베어링 표시는 몸체 Y69~73, 플랜지 Y73~74 | 원본의 명목 직경·깊이 참고. P1 뒤판 두께 6에서 안쪽 1은 관통 여유 |
| 반대편 지지축 | Ø4.9 Y63~77, 지지턱 Ø8 Y62~64, 코어 뒷벽 통과공 Ø5 Y61~69 | 5mm급 배치용 시험값. 실제 어깨볼트/부시/스페이서·축방향 고정 미정 |

부품 전체를 출력하기 전에 서보·혼·베어링 시험편을 실물에 맞춰 확인해야 한다. P1은 형상·배치 검토이며 최종 나사 체결 설계, 출력 후 끼움, 하중·수명·가동 범위 시험을 완료한 도면이 아니다. 코어 중심에서 혼과 베어링이 한 축선에 놓이는 것은 CAD에서 검증하며, 실제 서보 출력축 오프셋은 실측 후 재생성해야 한다.
