# v8 P2 — X1 Carbon 분할 출력과 베이스 조립

단위 **mm**, 배율 **100%**. 이 패키지는 부품별 출력 방향과 프린터 범위를 검토하기 위한 CAD 출력물이다. **슬라이싱·실제 출력·현품 끼움 시험은 수행하지 않았다.** 최신 부품 수와 형상 치수는 [출력 manifest](print/manifest.json), CAD 원본과 변경 이력은 이 폴더의 README를 기준으로 한다.

## 프린터 기준과 파일 선택

사용자 지정 프린터는 **Bambu Lab X1 Carbon**이다. 제조사 명목 출력 영역은 **256×256×256**이다. Bambu Studio 공식 X1 Carbon 0.4 mm 프로파일의 기본 높이 제한은 상속된 **250**이고, 전방 왼쪽 **X=0~18, Y=0~28**은 제외 영역이다. 이 패키지는 그 제외 영역을 유지한다.

- [제조사 명목 규격 PDF](https://public-cdn.bambulab.com/store/bambulab-X1-carbon-tech-specs.pdf?v=20241019045941)
- [공식 X1 Carbon 0.4 프로파일 — 제외 영역](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/Bambu%20Lab%20X1%20Carbon%200.4%20nozzle.json)
- [상속된 256×256 출력 영역](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/fdm_bbl_3dp_001_common.json) · [상속된 기본 높이 250](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/machine/fdm_machine_common.json)

공식 소스 확인일은 **2026-10-23**이다. 설치된 Bambu Studio 설정을 읽거나 변경한 결과는 아니다. 확인한 값과 출처는 [printer_evidence.json](print/printer_evidence.json)에 남긴다.

| 경로 | 내용과 용도 |
| --- | --- |
| `stl/*.stl` | CAD에서 내보낸 기준 형상. 조립 좌표 또는 원본 방향을 유지하므로 출력 방향으로 사용하지 않는다. |
| [print/oriented_stl](print/oriented_stl) | 출력 방향으로 회전하고 XYZ 최솟값을 0으로 이동한 STL. 부품당 1개다. |
| [print/single_part_3mf](print/single_part_3mf) | **부품당 1개 오브젝트만 넣은 3MF Core 모델**. 베드 중심 부근의 실제 XY 좌표와 바닥 Z=0을 저장한다. |
| [print/bed_overview.svg](print/bed_overview.svg) | 부품 경계상자, 5 mm 브림 예약, 제외 영역을 비교하는 배치 개요. 실제 레이어나 지지대 그림이 아니다. |
| [print/manifest.csv](print/manifest.csv) · [print/manifest.json](print/manifest.json) | 입력 파일 해시, 회전·이동 행렬, 출력 치수, 브림 예약 좌표, 3MF 재입력 검사 결과. |

3MF에는 **Bambu 프린터/재료/공정 프리셋, 실제 브림, 지지대, G-code가 들어 있지 않다.** Studio에서 파일을 열고 X1 Carbon과 실제 노즐·재료·플레이트를 선택해야 한다. 프로그램이 모델을 자동 재배치하면 manifest의 좌표와 달라질 수 있으므로 배치 개요와 비교한다.

부품 경계상자를 XY 각 방향으로 **5 mm 확장**한 직사각형이 베드 경계 안에 있고 제외 영역과 겹치지 않는지 보수적으로 검사한다. 베드 끝에는 별도로 **최소 1 mm**를 남긴다. 이는 부품의 모든 높이에 적용한 경계상자 검사다. 지지대 확대, 프라임 타워, 퍼지 라인, 노즐 이동 경로는 검사에 포함되지 않는다.

## 분할과 권장 배치

폭 **640**의 베이스는 X=-106.6667, +106.6667에서 **3등분**했다. 트레이와 뚜껑을 각각 3개로 나눠 각 부품의 폭은 약 **213.33**, 깊이는 **200**이다. 트레이 높이는 **96**, 뚜껑은 **4**이며 개별 출력 후 연결한다. 전체 베이스를 축소해서 출력하지 않는다.

| 부품군 | 출력 방향 | 확인할 점 |
| --- | --- | --- |
| 베이스 트레이 3개 | 평평한 외부 바닥을 베드에 둔다. | 열린 내부가 위를 향한다. 바닥 나사 머리 포켓과 핀 소켓의 작은 브리지·구멍 상태를 확인한다. |
| 베이스 뚜껑 3개 | 원래 아래 Z면을 베드에 둔다. | 얇고 넓은 부품이므로 휨·브림·표면을 미리보기에서 확인한다. |
| 곡선 팔 앞뒤 4개 | 앞은 X축 -90°, 뒤는 +90° 회전하여 **Y 분할면을 아래**로 둔다. | 기존 최대 226 mm축이 베드의 XY면에 눕는다. 기본 출력 영역은 약 **131×226**, 높이는 **36**이다. |
| 손 앞뒤 4개 | 앞은 X축 -90°, 뒤는 +90° 회전하여 **Y 분할면을 아래**로 둔다. | 기본 외형은 약 **172×90**, 높이 **34**. 혼 홈·베어링 포켓은 지지대 흔적이 없도록 접촉 부위를 검토한다. |
| 머리 앞뒤 | 앞은 X축 -90°, 뒤는 +90°로 **평평한 서비스 분할면을 아래**로 둔다. | 곡면 외장은 위를 향한다. 구멍·창 주변과 내부 지지대를 미리보기에서 확인한다. |
| 원형 칼라·휴대폰 받침 | 원래 아래 Z면을 베드에 둔다. | 칼라의 링 바닥과 받침의 넓은 발을 접촉면으로 사용한다. |
| 새 베이스 연결판 4개 `SEAM_SPLICE_*` | **X축 180° 회전**, 너트 포켓이 있는 윗면을 아래로, 정렬 핀을 위로 둔다. | 아래로 돌출된 핀 때문에 원래 아래면을 베드에 놓으면 판이 떠 있게 된다. 이 방향은 핀 지지대를 줄이는 안이다. 아래쪽 5.8 mm 너트 포켓의 브리지를 확인한다. |
| 얼굴 베젤·새 이름의 부품 | 6개 축 방향 중 실제 평면 삼각형의 접촉 면적이 가장 큰 방향을 자동 선택한다. | manifest에 `automatic_review_required`로 기록한다. 곡면 품질·하중 방향·서포트가 확정된 방향은 아니다. |

표의 치수는 기존 기본 형상 설명이다. 최신 추가 보스·핀·구멍을 포함한 실제 출력 치수는 manifest의 `oriented_bbox_mm`를 따른다. 판 중앙 배치를 우선하고, 제외 영역에 걸리는 베이스는 필요한 만큼 오른쪽 또는 뒤로 옮긴다. 기본 베이스 형상은 약 **X=130.67, Y=128**의 경계상자 중심으로 오른쪽 이동하면 5 mm 브림 예약까지 제외 영역을 피한다.

각 3MF는 한 부품씩 출력하는 보수적인 배치다. 여러 작은 부품을 한 판에 모으려면 Studio에서 상호 간격·브림·지지대·출력 순서를 다시 검사한다.

## 베이스를 이어 붙이는 구조

v8 P2는 원래 후방 바닥 연결판 2개를 바꾸고 전방 연결판 2개를 더해, **이음부 2곳 × 전후 2개 = 연결판 4개**로 잇는 구조다.

| 항목 | CAD 시험값 |
| --- | --- |
| 연결판 `SEAM_SPLICE_{1,2}_{FRONT,REAR}` | 몸체 **48×44×8**, 아래 정렬 핀 돌출 약 **2**, 전체 높이 약 **10** |
| 조립 위치 | 이음부 X=±106.6667, 전후 Y=±62. 연결판 몸체 Z=4~12 |
| 연결판 볼트 구멍 | 판당 4개, Ø**3.4**, 중심 오프셋 X=±12, Y=±14 |
| 너트 | **M3 DIN 562 사각 너트**, 명목 5.5×5.5×1.8. CAD 포켓 **5.8×5.8**, 깊이 **2.2** |
| 볼트 | **M3×10 ISO 7380 낮은 버튼 머리**를 기준으로 검토. 명목 머리 Ø5.7, 높이 1.65 |
| 바닥의 머리 포켓 | **6.4 사각 × 깊이2.2**. 바닥 아래로 머리가 나오지 않게 하는 시험 형상 |
| 정렬 핀 / 소켓 | 핀 Ø**4**, 소켓 Ø**4.4**, 소켓 깊이 **2.3**. 지름 차이 0.4는 시험 공차 |
| 베이스 연결용 수량 | **볼트 16개 + 사각 너트 16개**. 뚜껑·팔·관절 등 다른 체결품은 별도 |
| 스피커 하부 여유 | BA-R9 외형 하단 Z=16, 연결판 상단 Z=12로 정적 배치상 **4**. 배선·실물 공차는 별도 |

위 하드웨어와 공차는 **설계 시험값**이다. 실제 구매품의 머리·너트 외형, 필라멘트 수축과 구멍 크기를 대조해야 한다. 출력 성공이나 단면 간섭 없음이 체결 강도·나사 물림 검증을 의미하지 않는다.

조립 순서는 다음과 같다.

1. 큰 외장보다 연결판 1개와 해당 바닥 구멍 주변의 작은 시험편을 먼저 검토·출력한다. 핀·소켓, 사각 너트와 볼트 머리 포켓이 맞는지 확인한다. 시험편 별도 형상이 없는 경우 전체 부품을 시험편으로 오인하지 않는다.
2. 트레이 3개를 평평한 면 위에서 640 mm 전체 폭에 맞춰 임시 정렬한다. 맞댐면과 위쪽 테두리가 어긋나지 않게 잡는다.
3. 내부에서 전후 연결판의 정렬 핀을 각 소켓에 넣는다. 너트 포켓을 위로 향하게 하고 사각 너트를 앉힌다.
4. 바닥 아래에서 M3×10 볼트를 끼우고 내부 연결판의 너트와 체결한다. 판당 4개, 전체 16개다. 머리가 바닥 밖으로 튀어나오는지, 핀이 바닥을 뚫거나 판이 뜨지 않는지 확인한다. 출력 플라스틱이 눌릴 정도로 과하게 조이지 않는다.
5. 스피커와 부품을 임시 배치하고 연결판·볼트·배선의 실제 여유를 확인한다. 기존 뚜껑은 별도 구멍으로 체결하며 연결판 볼트와 공용으로 쓰지 않는다.

접착은 **원할 때 베이스 맞댐선 보강용**으로만 검토한다. 볼트 체결로 형상을 확인한 뒤 재료와 맞는 접착제를 선택한다. 머리·팔·손의 서비스 분할면, 혼, 베어링, 축 주변은 영구 접착하지 않는다. 현품 끼움이나 배선이 확정되기 전 접착하면 재작업이 어려워진다.

## 아직 확인해야 할 사항

현재 검증은 파일의 폐합·단일 메시, 방향 변환, 프린터 경계·제외 영역·브림 예약, 3MF 내용 재입력까지다. 실제 접착, 볼트 체결, 슬라이싱, 프린터 출력 시험은 남아 있다.

손 앞뒤는 새 P2에서 한쪽당 M3×65 볼트 2개와 Ø4×6 별도 맞춤핀 2개로 체결하도록 수정했다. 일반 너트와 OD7 와셔를 쓰는 시험안이며 구매품의 실제 치수·길이·공구 접근은 확인해야 한다. `HAND_DOWEL_4x6` 모델은 **4개 출력**한다. 각 손의 분할면은 Y40이고 핀이 일체 돌출되지 않아 분할면을 아래로 둘 수 있다. 자세한 홀·소켓·혼·베어링 자리는 [손 설계 설명](source/HANDS_NATIVE.md)에 있다.

특히 서보 혼·출력축 오프셋, 베어링 유지·반대편 지지축 고정, Yaw 지지, 머리 서비스 커버 체결, 얼굴 보드 및 확산창 고정은 최신 CAD README의 미확정 항목과 함께 확인한다. 단순한 앞뒤 분할과 실제로 체결 가능한 구조를 구별해야 한다. 슬라이서의 레이어 미리보기에서 구멍 막힘·얇은 벽·공중 시작·지지대 제거 경로를 확인한 뒤 실제 출력으로 진행한다.

## 다시 생성하기

저장소 루트에서 다음을 실행한다. 기존 STL을 수정하지 않고 `print/` 아래 결과를 만든다. 새 연결판·핀 등도 `stl/*.stl` 검색으로 포함한다.

```powershell
python -B doc/BOM/mechanical_v8/source/pack_x1c.py
```

[생성 스크립트](source/pack_x1c.py)는 저장소의 `tmp/cad-runtime`에 있는 numpy와 trimesh를 우선 사용한다. 출력 형상이 바뀌면 최신 CAD에서 STL을 다시 내보낸 후 이 스크립트를 다시 실행한다. `manifest.json`의 입력 SHA-256을 대조해 현재 STL과 같은 버전인지 확인한다. 폴더에 폐기한 STL을 남겨 두면 그것도 출력 대상으로 검색되므로 최신 부품만 유지한다.
