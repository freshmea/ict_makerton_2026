# P5 RPY 전용 분할 출력·조립 안내

2026-10-23 · mm · **최종 배포 메시·정적 배치29종/32개 대조 완료. 실제 슬라이싱·출력은 미검증**

P5는 좌우 각 **Yaw → Shoulder Pitch → Wrist Roll**의3회전 DOF를 만든다. 마지막 손목은 실제 서보·혼·코어·베어링·캡이 X축에 놓이는 구조다. P4의 두 Pitch 손목과 부품을 혼용하지 않는다. 특히 같은 이름의 `L/R_CURVED_ARM_CORE_FRONT/REAR`도 P5에서 상부가 바뀐다.

## 파일 선택과 출력판

- [출력판별 묶음표 — 16판·29종·32개](PRINT_PLATES.md): 같은 판에 넣을 STL과 수량, 배치 그림, 권장 출력 순서를 확인한다. 경계상자 기준 제안이며 실제 슬라이싱 전이다.
- 이 폴더의 `cad/`·`stl/`는 P5 원형 파일이다. 조립 좌표를 유지하므로 출력에는 최종 `print/oriented_stl/` 또는 `print/single_part_3mf/`를 사용한다.
- [P5 출력 목록](PARTS.md)은 `source/geometry_P5_parts.json`과 [출력manifest](print/manifest.json)의 부품·수량·해시를 대조해 생성했다. 서보 케이스·금속 축·혼·베어링 표시 바디를 출력 수량에 넣지 않는다.
- `print/manifest.json`의 방향·좌표·경계상자와 검증 한계를 확인한다. 3MF는 단일 부품 모델·좌표이며 Bambu 재료/공정 프로파일·실제 브림·서포트·G-code를 포함하지 않는다.
- 편집과 운동 설정은 상위 `cad/fold_wing_v8_P5_RPY.solidcraft`와 [P5 조립·6축 구동 안내](../source/ASSEMBLY_JOINTS_P5.md)를 사용한다.

STL을 **mm·100%**로 가져온다. 출력 장비는 Bambu Lab X1 Carbon이며 제조사 체적256³mm와 별도로 기본 프로파일 높이250mm·앞왼쪽18×28mm 제외영역·가장자리1mm·브림5mm 예약을 정적 배치에서 검사한다. 실제 브림과 툴패스를 만든 검사는 아니다. 슬라이서 자동배치·가운데정렬 후에는 제외영역과 여유를 다시 확인한다.

출력 방향은 최종manifest의 개별 후보를 따른다. 팔4개는 앞뒤 분할면을 아래로 눕혀 약126×219×40mm, 손 요크는 약154.99×87.98×106.99mm, 분리 베어링 캡은 약88×106.99×6mm다. 최대 출력 높이는106.99mm다. 어깨 터릿의 Yaw 원판을 아래로 놓으면 Y축Ø74 공동의 천장·레일에 서포트가 필요할 수 있다. 새 팔의 X축 코어 공동·케이스 레일·보스, 손 요크의 캡·후방 브리지·혼 홈과 너트 좌석도 슬라이서에서 확인한다. `automatic_review_required`는 자동 방향 후보이므로 내부 서포트 제거·나사 접근·평면 접촉·강도 방향을 검토한다. 외형이 출력판 안에 들어가는 것과 출력 성공은 별개다.

노즐·재료·벽수·인필·레이어·서포트 공정은 미확정이다. 실제 서보 케이스·혼·베어링·핀·너트를 맞추는 작은 시험부터 진행한다. Ø3.4 M3 홀, Ø4 맞춤핀/소켓, 베어링16.3/18.2, 십자 혼 홈과 사각너트5.8 등의 치수는 현품 확인 전의 CAD 끼움 시험값이다.

## P5에서 바뀐 부품

베이스 트레이3개·뚜껑3개·전후 연결판4개, 몸체·머리·바이저·휴대폰 받침과 J1 칼라를 유지한다. P4에서 추가한 좌우 어깨 터릿도 유지한다. 새 팔은 하부 어깨 캡·브리지를 유지하고 **Z270 이상 옛 Y축 손목을 잘라 X축 손목 코어로 교체**한다. 출력 원본은 P5에서 다시 내보낸 파일로 통일한다.

손은 기존 앞뒤2부품에서 **한쪽당3부품**으로 바뀐다.

| P5 손 부품 | 조립 역할 |
| --- | --- |
| `L/R_ROLL_YOKE_PALM_FRONT` | 안쪽Ø88 캡·후방 방사 브리지·앞 목·앞 손바닥의 일체 출력물, 혼 구동측 |
| `L/R_ROLL_PALM_REAR` | 뒤 목·손바닥, 손 내부 접근용 분리 절반 |
| `L/R_ROLL_BEARING_CAP` | 바깥Ø88 캡·연결 귀, 반대편 베어링을 넣고 마지막에 닫음 |

느슨한 `HAND_DOWEL_4x6`는 한 파일을 **4개**, 손당2개 출력한다. 다른 출력물은 각각1개로 **29종·총32개**다. 28개 구조물+핀1종을manifest와 대조했고 원형STL·방향STL·3MF의 해시87개와 수량을 확인했다. [목록·해시 대조 기록](../source/P5_files/print_list_checks.json). P4의27종·30개와 섞지 않는다.

## 접합과 조립

1. **베이스:** 트레이3개를 정렬키·전후 연결판4개·M3 체결로 잇는다. 전장·스피커·배선 접근을 확인한 뒤 뚜껑3개를 닫는다. 접착은 베이스 맞댐선의 선택 보강이며 서비스 뚜껑을 영구 접착하지 않는다.
2. **Yaw·어깨:** 몸체 J1 케이스를 고정하고 출력 혼에 터릿을 연결한다. 터릿 안 J2 케이스·고정 지지축을 맞추고 팔 앞뒤의 Ø88 캡을 혼·베어링에 정렬한다. 위 브리지 두 M3로 팔 앞뒤를 묶는다. 고정 코어를 관통해 회전 캡과 같이 조이지 않는다.
3. **손목 고정측:** 팔 앞뒤 X축Ø80×54 코어에 J3 케이스·레일·반대편 고정축을 조립한다. 코어 앞뒤의 네 보스Ø3.4 Y축 홀은 고정측 체결용이다. 실제 플랜지·케이블 삽입 동선·나사머리·너트·길이는 현품 대조 대상이다.
4. **안쪽 요크:** 바깥 베어링 캡을 열어 둔 채 서보 출력축·혼을 안쪽 캡 포켓에 맞춘다. 실제 혼과 중심 나사 체결에 접근할 수 있을 때 먼저 고정한다. 캡과 고정 코어 끝의 중립 간격은1mm다.
5. **손바닥:** 앞뒤 목의 맞춤핀2개를 넣고 두 M3로 손바닥을 묶는다. 핀은 별도 부품이므로 출력면에서 돌출된 핀 때문에 나머지 면이 뜨는 구조가 아니다. 조명·확산판·볼트끝·배선 여유를 확인한다.
6. **바깥 캡:** F625계열 표시 기준 베어링을 캡 자리에 넣고 팔의 고정축과 맞춘다. 캡을 마지막에 닫고 Y90/Z310·320 두 위치의 **X방향 M3**로 후방 요크에 체결한다. 요크5.8mm 사각너트 홈과 캡 바깥Ø6.4mm 머리홈을 이용한다. 축방향 유지·스페이서·너트 포획·볼트 길이는 실측 전이다.
7. **회전 확인:** 고정 코어·케이스·지지축은 팔에 남고 요크·손바닥·바깥캡은 손과 함께 Roll한다. 전원 없이 걸림·축정렬·배선을 확인한 뒤 CAD 개별/누적 구동과 실제 PWM 시험을 각각 진행한다.

손바닥 목·베어링캡·코어 보스는 서로 다른 방향과 길이의 체결부다. 기존 손의 긴M3 볼트 시험값을 새 세 체결부에 일괄 적용하지 않는다. 실측·하중 검토 전 접착만으로 모터 하중을 전달하는 완성 구조로 보지 않는다.

## 출력 메시 검사와 확인 범위

P5 출력 STEP29종은 유효한 단일 닫힌 솔리드다. 최초 SolidCraft 직접 STL에서는 나머지25종은 폐합했지만 **수정 팔4종은 비폐합 메시**였다. 이 네 파일은 같은 네이티브 STEP을 OCP로 재테셀레이션했고, 왼앞 팔은 추가로 면적0.002514894421mm²의 누락 삼각형1개를 수선했다. 이 과정은 출력 메시만 바꾸며 `.solidcraft`·STEP 원본 형상은 바꾸지 않는다. 최초 직접 내보내기와 최종 배포 메시의 결과를 구분한다. [최초 메시 검사](../source/P5_geometry_files/initial_mesh_QA.json) · [재테셀레이션·수선 근거](../source/P5_geometry_files/arm_tessellation.json).

수선한 삼각형의 원 STEP 표면7점 표본 최대거리는0.001271895016mm, 네 팔의 STEP 대비 메시 체적 상대차 최대는0.2852122637%, 경계상자 차이 최대는0.003326516mm다. 이는 해당 디지털 비교 결과이며 실제 출력 공차·실측·끼움 허용오차를 뜻하지 않는다. 최초STL·OCP 원메시·해시와 수선 로그도 보존했다.

최종 배포 STEP29종의 유효·단일 닫힌 솔리드, 원형STL29·방향STL29·3MF29의 폐합·방향일관·양체적·단일 연결 성분을 [독립 전수검사](../source/P5_geometry_files/print_geometry_QA.json)했다. 3MF 정점은 원STL과manifest 변환에 일치했고87해시·브림예약·출력판·제외영역·250mm 높이 검사를 통과했다. 전체29종의 STEP 대비 메시 경계상자 차이 최대0.0202332543mm, 체적 상대차 최대0.7834236615%는 기존 머리 뒤 외장의 테셀레이션/적분 차이다. 네 팔의0.2852122637%와 구별하며 물리 출력 공차로 보지 않는다. 삼각형 자체 교차·슬라이서 가져오기·서포트/툴패스는 검사하지 않았다.

선택 간섭·네이티브 엔진 동작·GUI 각도 변경·실제 슬라이싱·실물 출력·부하 구동은 각각 별도로 기록한다. 이전 P4 결과를 새 X동축 손목의 검증으로 사용하지 않는다.
