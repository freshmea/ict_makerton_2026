# SolidCraft 네이티브 손 외장 P2

2026-10-23 · mm · 실물 끼움·체결·회전 하중 시험 전.

## 원본과 설계 범위

v7의 `L/R_WRAP_HAND_FRONT/REAR` 네 STEP는 CadQuery에서 유효한 닫힌 솔리드였지만 SolidCraft에서는 열린 바디 경고가 발생했다. P2는 해당 STEP를 재직렬화하거나 외형 동등 수리했다고 주장하지 않는다. 지정한 **SolidCraft 0.20.0 portable의 CLI**가 새 네이티브 파라미터·스케치·extrude·Boolean 이력으로 손을 다시 만든다. 사용자 GUI나 공유 MCP 세션을 사용하지 않았다.

검토한 공식 가이드는 저장소 `tmp/solidcraft-official/solidcraft-{modeling,editing,checking}.md` 및 `solidcraft-modeling-reference.md`다. 초기 빈 headless 설계를 확인하고, 단계별 측정, dof 0, 이력 오류·경고, STEP 재가져오기, 파라미터 왕복을 확인했다.

파일:

- `build_hands_native.py`: 네 손의 설계 JSON과 각 `.solidcraft/.step/.stl` 생성기.
- `hands_native.json`: 네 손을 새 설계 또는 기존 설계 뒤에 replay하는 **실행 가능한 commands script**. 네 손의 모든 파라미터·스케치·feature 이름은 `L_WRAP_HAND_FRONT__` 등의 접두사로 구별한다.
- `L/R_WRAP_HAND_FRONT/REAR.json`: 개별 부품 명령 원본. 단독 설계용 파라미터 이름이다.
- `hand_dowels_assembly.json`: 실제 조립 좌표에 놓이는 느슨한 맞춤핀 4개 명령. 손 네 바디와 별도로 통합한다.
- `HAND_DOWEL_4x6.json`: 별도 출력용 핀 한 개의 네이티브 원본. **4개 출력**한다. 실측한 Ø4×6 매끈한 기성 핀으로 대체해도 된다.
- `cad/`: 세계좌표를 유지한 네 부품의 네이티브 저장본·STEP·STL 및 GPU 스크린샷. `hands_native_all.solidcraft`는 손 네 부품만 있는 통합 설계다.
- `verify_hands_native.py`, `hands_native_verification.json`: STEP/STL 독립 검사, 별도 headless MCP 재가져오기, 실제 v7 코어 정지 자세 간섭, 파라미터 왕복 검사.

## 유지한 기구 기준과 변경한 형상

손목 축은 X=±220, Y=40, Z=315이다. 고정 코어 Ø80, Y13~67을 유지한다. 움직이는 원형 앞 캡은 Ø90, Y6~12, 뒤 캡은 Ø90, Y68~74다. 전후 서비스 분할면은 **Y40**이다.

원래 비균일 변환 타원체로 만들었던 손바닥·손가락은 **둥근 캡슐 스케치의 네이티브 extrusion**으로 다시 설계했다. 손바닥 전체 범위는 X방향80, Z방향42, Y13~67이며, 공동은 X73.6×Z35.6, 기본 벽3.2다. Y축 방향 옆면은 v7의 타원체 팽창 곡률과 다르다. 손가락은 고정 캡슐 3개이며 구동 관절이 없다. 외형 치수와 곡선 인상은 유지하되 원본 표면의 정밀 복제는 아니다. 손바닥 바닥에는 상태 LED 확산부를 위한 40×26 개구가 있다. 광학 렌즈 구동부는 없다.

코어 외곽 연결 브리지는 축에서 손 안쪽으로 **radial X41~63**, Z305~325, Y11~69에 있다. 코어 R40에 대해 최소 X방향1 mm 간극을 두고, 실제 원본 코어 전후와의 교차 체적도 검사했다. 이 검사는 현재 정지 자세에 한정된다.

앞 혼 포켓은 span30×팔폭6.4×**실제 캡 안 깊이2.7**의 십자다. 중심 나사 접근 구멍은 Ø5.3이다. 원본 혼의 이빨·스플라인을 복제한 것이 아니므로 현품 혼 실측이 필요하다. 뒤 베어링 자리는 Ø16.3, 플랜지 Ø18.2×깊이1을 유지했다.

## 전후 정렬과 접합

한 손당 **M3 볼트 2개 + 느슨한 Ø4×6 맞춤핀 2개**를 사용한다. 이동하는 손 외장 전후끼리 체결하며, 고정 코어까지 관통해 조이지 않는다. 접착제만으로 버티는 관절로 설계하지 않았다.

| 항목 | 시험 설계값 |
|---|---|
| M3 통과홀 | Ø3.4, 손목 중심에서 손 안쪽 radial50, Z=315±5 |
| 볼트가 물리는 브리지 길이 | 앞 Y11~40 29 + 뒤 Y40~69 29 = **58 mm** |
| 볼트 접근 | 앞 머리 Y11, 뒤 너트 Y69. 홀 축은 cap R45 밖 radial50이므로 OD7 와셔도 캡을 피함 |
| 권장 시험 볼트 | **M3×65 2개/손**, 와셔·너트 별도. 보유품 확인 전 구매 확정 규격은 아님 |
| 길이 계산 예시 | 재료58 + 와셔2개 합1.6 + 너트2.4 =62 mm, 볼트65면 약3 mm 나사 끝 여유. 와셔·너트의 실제 두께와 머리 외경을 확인해야 함 |
| 너트 처리 | 뒤쪽에서 일반 너트를 공구로 잡는 관통 체결. 포획 너트·열삽입 인서트 구조는 넣지 않음 |
| 맞춤핀 소켓 | Ø4.4, radial60, Z=315±4. 앞 Y36.8~40, 뒤 Y40~43.2로 **각3.2 mm blind pocket** |
| 맞춤핀 | Ø4×6, 조립 좌표 Y37~43. 합 소켓6.4에 축방향0.4 여유 |
| 접착제 | 필요할 때 느슨한 핀 한쪽만 소량 고정 가능. 회전 코어·혼·베어링에는 유입시키지 않음 |

조립은 서보·혼·베어링의 접근 및 방향 확인 → 앞·뒤 외장에 핀 맞춤 → M3 볼트와 와셔·너트로 전후 체결 → 손이 코어와 간섭하지 않고 움직이는지 수동 확인 순서다. 서보 중심 나사와 베어링 유지부, 반대편 지지축의 이탈 방지는 별도 미확정 인터페이스다. M3 볼트를 조인 사실만으로 이 문제가 해결되지는 않는다.

## 출력 방향

핀을 일체 돌출시키지 않아 네 외장의 Y40 분할면을 평판에 둘 수 있다. 앞 외장은 Y40을 아래로, 뒤 외장은 Y40을 아래로 향하게 각각 회전시킨다. 현 좌표의 STL은 조립 세계좌표를 유지하므로 실제 슬라이서에서는 개별 배치와 바닥 정렬이 필요하다. 최종 출력 패키지가 별도 배치한 STL을 제공하면 그 파일을 사용한다.

각 외장 경계상자는 **172×34×90 mm**, 핀은 **4×4×6 mm**이다. 캡·공동·베어링 자리의 돌출부에 서포트가 필요한지는 슬라이서 결과로 확인해야 한다. 출력 방향 제안은 실제 슬라이싱이나 출력 품질 검증을 대신하지 않는다. 큰 외장 전에 핀/소켓과 혼·베어링 끼움을 작은 시험편으로 확인한다.

## 검증 결과

- 네 파일 모두 원본 네이티브 이력 **24 features**, 스케치 9/10개, dof 0, feature error/warning 없음.
- 네 손 통합 replay: **4 bodies, 96 features, 38 sketches**, 전 스케치 dof 0, error/warning 없음.
- 각 STEP를 CadQuery/OpenCascade에서 독립 재입력: 유효 BREP, **단일 솔리드·단일 닫힌 셸**. 각 STL은 watertight 및 양의 유향 체적.
- 지정 CLI의 새 **headless MCP**에서 네 STEP를 각각 다시 열었을 때 `errors:0`, `warnings:[]`.
- 실제 v7 전체 STEP에서 원래 코어 전후를 부피·외형·좌우 좌표로 대응한 뒤 새 손과 교차: 8쌍 모두 교차 체적0. 새 손 앞뒤 2쌍도0.
- `cap_d, palm_l, palm_h, wall, bolt_d, dowel_d, fit`의 명시된 허용 최솟값/최댓값/기본값을 순서대로 변경한 **84상태** 모두 이력·스케치·단일 셸 검사 통과. 기본값 복귀 시 체적 복원. 볼트 지름 변화의 체적은 독립 원통 계산과 최대 약0.038 mm³ 차이.

| 부품 | P2 STEP 체적 mm³ | v7 기본 적분 체적 mm³ | 의도된 증가 mm³ |
|---|---:|---:|---:|
| L 앞 | 76,700.344 | 59,640.857 | 17,059.487 |
| L 뒤 | 76,395.838 | 59,336.350 | 17,059.488 |
| R 앞 | 76,700.344 | 59,638.937 | 17,061.406 |
| R 뒤 | 76,395.838 | 59,335.027 | 17,060.811 |

체적 증가는 캡슐 손바닥과 넓힌 브리지의 의도적인 재설계 결과다. v7 타원체는 적분 설정에 따라 체적이 달라졌으므로 위 비교는 CadQuery 기본 적분값끼리이며 정밀 표면 동등성 판정으로 사용하지 않는다. P2의 SolidCraft 측정과 OpenCascade 기본 체적도 약1 mm³ 차이가 있어 각각의 원시 측정값을 보존했다.

하중, 회전 전 범위, 케이블 굽힘, 마찰·유격, 볼트/핀 실제 끼움, 실물 출력은 검증하지 않았다. 이 네 손의 닫힌 네이티브 이력 확보와 제품 전체의 조립·구동 검증은 서로 다른 결과다.
