# P5 조립·6서보·Yaw / Pitch / Roll 구동 안내

2026-10-23 · mm · **P5 형상 생성·구동·출력 검증 진행 중**

**구동 원본은 [cad/fold_wing_v8_P5_RPY.solidcraft](../cad/fold_wing_v8_P5_RPY.solidcraft)다.** `*_geometry.solidcraft`는 조인트 연결 전 중간 형상 체크포인트이며 최종 구동 파일이 아니다. [열기 실행 파일](../Open_SolidCraft.cmd)은 P5 RPY 원본을 지정한다.

최신 요구사항은 **서보6개, 왼팔3개·오른팔3개, 팔당 Yaw → Shoulder Pitch → Wrist Roll의 직렬3DOF**다. 마지막 J3는 손 길이 방향의 Roll이다. P4의 두 Pitch 구성을 보존하되 최신 제작본으로 사용하지 않는다. 손목 조인트 이름만 바꾸지 않고 서보 케이스·출력축·혼·코어·반대편 베어링·외장을 X동축 구조로 다시 만든다.

## P5 파일과 검증 범위

- [P5 편집·구동 원본](../cad/fold_wing_v8_P5_RPY.solidcraft) — 형상과 실제 회전 조인트·Ground·강체 관계·운동 연구를 함께 저장한 파일이다.
- [형상 생성기](build_geometry_P5.py), [구동 생성기](build_motion_P5.py), [실행 명령 원본](motion_P5.json). STL에는 편집 피처·조인트·운동 연구가 없다.
- 최종 도면 예정: `drawings/FWB_v8_P5_RPY_A3.pdf`, 동작 GIF 예정: `renders/P5_six_joint_demo.gif`.
- P5 전용 출력은 `P5/cad/`, `P5/stl/`, `P5/print/`를 사용한다. 기존 P2/P4 팔·손목 파일과 혼용하지 않는다.
- 최종 묶음 예정: `Fold_Wing_Buddy_v8_P5_RPY.zip`. **P4 ZIP은 미발행·제공 제외**다.

현재 P5에79바디·스케치74개(dof0),6revolute·7Study를 저장했고 타임라인 오류·경고0을 확인했다. 형상 이력513개에 그룹 이동48개(`BodyTransferFeature`)를 더한 최종 타임라인은561개다. 독립 재열기·엔진 구동·출력 검사는 진행 중이며 해당 P5 근거를 아래 표에 반영한다. 사용자 Escape로 화면 제어를 중단한 뒤 P5를 GUI에서 추가로 열거나 각도를 시험하지 않았다. 이전 P4의 화면·구동 결과를 P5 결과로 대신하지 않는다. 현품 실측·서보 PWM 구동·토크·하중·실제 출력 시험은 별도다.

## 여섯 서보와 고정측·회전측

```text
몸체·베이스 — Ground
├─ L_J1_YAW → P5_L_YAW_CARRIER:1
│  └─ L_J2_SHOULDER_PITCH → P5_L_ARM:1
│     └─ L_J3_WRIST_ROLL → P5_L_HAND:1
└─ R_J1_YAW → P5_R_YAW_CARRIER:1
   └─ R_J2_SHOULDER_PITCH → P5_R_ARM:1
      └─ R_J3_WRIST_ROLL → P5_R_HAND:1
```

| 축·보유 서보 배정 | 케이스를 고정하는 링크 | 출력측과 함께 움직이는 링크 |
| --- | --- | --- |
| 좌우 J1 Yaw 각1개 | 몸체·베이스 | Yaw 터릿·어깨 케이스와 그 위의 팔·손 전체 |
| 좌우 J2 Shoulder Pitch 각1개 | 각 Yaw 캐리어 | 곡선 팔·손목 코어·손목 케이스·손 전체 |
| 좌우 J3 Wrist Roll 각1개 | 각 곡선 팔의 X축 손목 코어 | 손 요크·앞 손바닥·뒤 손바닥·분리 베어링 캡·맞춤핀·혼 |

사진으로 확인한 보유 서보6개를 모두 위 여섯 위치에 배정한다. [재료 목록](../../재료%20목록.md)의 B01 수량을 늘린 것은 아니다. 실제 모델 일치 여부·플랜지·출력축 오프셋·혼·전압·전류·PWM·물리 회전한계는 실측 전이다.

`P5_L/R_YAW_CARRIER`에는 어깨 터릿·어깨 서보 케이스·어깨 고정 지지축이 속한다. `P5_L/R_ARM`에는 팔 앞뒤·손목 서보 케이스·손목 고정 지지축, J2 출력축·혼·베어링 표시와 팔 RGB 표시가 속한다. `P5_L/R_HAND`에는 손의 출력3부품·맞춤핀2개와 J3 출력축·혼·베어링 표시가 속한다. 정확한 전체 멤버는 [형상 그룹 원본](geometry_P5_groups.json)과 생성 후 `P5_files/group_mapping.json`을 대조한다.

각 그룹 내부는 함께 움직이는 강체 관계로 묶는다. **서보 케이스와 그 서보의 출력측 혼을 같은 강체 그룹에 넣지 않는다.** J2의 고정 지지축은 Yaw 캐리어에, J3의 고정 지지축은 팔에 남는다. Ground는 몸체 기준에만 적용한다. Browser의 폴더 부모와 운동 조인트의 부모는 별개이며, 팔·손을 Ground하면 회전이 잠길 수 있다.

베어링은 표시용 단일 외형 바디다. 내륜·외륜·볼의 상대 운동이나 베어링 수명·하중 해석을 구현한 것은 아니다. 출력 부품 수량에 서보·금속 축·혼·베어링 표시를 넣지 않는다.

## 여섯 회전 조인트의 좌표와 독립성

X는 좌우, Y는 앞뒤, Z는 위쪽이며 앞은 -Y다. 다음은 **모든 각도0°인 중립의 world 좌표**다. 생성기는 실제 `revolute` 6개를 `joint.as_built`로 만들고, 조인트 프레임을 부모 링크에 붙인다.

| 조인트 | 부모 → 자식 | 원점 XYZ | 중립의 양의 회전축 | 중립 | 임시 CAD 제한 |
| --- | --- | --- | --- | --- | --- |
| `L_J1_YAW` | 몸체 → 왼쪽 Yaw 캐리어 | `[-275,40,130]` | `[0,0,1]` | 0° | -15°~+15° |
| `L_J2_SHOULDER_PITCH` | 왼쪽 Yaw 캐리어 → 팔 | `[-275,40,180]` | `[0,1,0]` | 0° | -15°~+15° |
| `L_J3_WRIST_ROLL` | 왼쪽 팔 → 손 | `[-220,40,315]` | `[1,0,0]` — 손 안쪽 | 0° | -15°~+15° |
| `R_J1_YAW` | 몸체 → 오른쪽 Yaw 캐리어 | `[275,40,130]` | `[0,0,1]` | 0° | -15°~+15° |
| `R_J2_SHOULDER_PITCH` | 오른쪽 Yaw 캐리어 → 팔 | `[275,40,180]` | `[0,1,0]` | 0° | -15°~+15° |
| `R_J3_WRIST_ROLL` | 오른쪽 팔 → 손 | `[220,40,315]` | `[-1,0,0]` — 손 안쪽 | 0° | -15°~+15° |

중립에서 J1은 Z, J2는 Y, J3는 X인 서로 독립된 세 회전축이다. J1을 돌리면 J2·J3의 원점과 축이 함께 이동하고, J2를 돌리면 J3와 손목·손이 함께 따라간다. J3 자체는 이동한 손 길이축을 중심으로 손을 비튼다. 초기 world X/Y/Z를 매번 고정해서 적용하는 세 회전과 구별한다.

J1=θ, J2=φ일 때 J3의 world 축은 `Rz(θ) Ry(φ) [1,0,0]`(왼쪽), `Rz(θ) Ry(φ) [-1,0,0]`(오른쪽)이다. 손목 원점 W는 어깨 원점 S를 기준으로 `S + Ry(φ)(W-S)`로 이동한 뒤 J1 원점 B 주위의 `B + Rz(θ)(…-B)`를 따른다. J3 자체 회전으로 손목 원점이 이동하지는 않는다. 부모를 먼저 구동한 뒤 자식 축·원점과 손의 실제 변위를 확인해야 한다.

양의 각도는 각 표기축의 오른손 법칙이다. 좌우 같은 +각도가 같은 시각적 손동작을 뜻하지 않는다. 양팔 자동 동기화·서보 전기적 반전·PWM 보정은 이 축 표만으로 설정되지 않는다. 중립0°는 CAD 저장 자세이며 실제1500μs 또는 서보90° 명령이 아니다. **±15° 제한과 ±10° 시험은 CAD 데모용 잠정값으로, 충돌 없는 연속 범위나 하드웨어 허용각이 아니다.**

## 손의 3부품과 분리 베어링 캡

각 손은 다음 **출력3부품**으로 나눈다. 기존 손바닥 중심±139·손가락 중심±105와 둥근 캡슐형 외곽을 유지하고 구동부를 X축으로 바꾼다.

| 부품 이름 접미사 — 좌우 각각 | 구성·치수 | 역할 |
| --- | --- | --- |
| `ROLL_YOKE_PALM_FRONT` | 안쪽Ø88×6 캡(a28~34), 후방 방사 브리지·앞 목·앞 손바닥을 일체화 | J3 출력 혼과 연결하는 회전 요크다. 앞 목은 a29~70, Y11~40, Z305~325다. |
| `ROLL_PALM_REAR` | 뒤 목·뒤 손바닥, 목a34~70·Y40~69·Z305~325 | 손바닥 뒤쪽을 열어 조명·체결 접근을 확보한다. |
| `ROLL_BEARING_CAP` | 바깥쪽Ø88×6 캡(바깥거리28~34)과 위 귀 | 반대편 베어링을 담고 마지막에 닫는 별도 회전 부품이다. |

고정 코어 끝은±27, 회전 캡의 안면은 안쪽·바깥쪽 모두28이므로 중립 축방향 간격은 **각1 mm**다. 뒤 방사 브리지는 안쪽거리a=-28~30(축방향58), **Y81~103·Z305~325**다. Ø80 코어의 최대Y80과 브리지의 최소Y81 사이 중립 간격도1 mm다. 이 치수만으로 회전 전 범위의 무간섭을 확정하지 않는다.

안쪽 캡에는 YZ면 닫힌 십자 스케치로 span30×팔폭6.4, 절삭3.7의 혼 포켓을 만든다. 캡 안 실제 포켓 깊이는2.7이며 중심 접근홀은Ø5.3이다. 표시 혼은29.6×6 십자·두께2.2로 홈보다 작게 잡은 시험 외형이며 실제 서보 스플라인 복제품이 아니다.

바깥 캡의 베어링 관통 자리는 **Ø16.3**, 바깥 플랜지 자리는 **Ø18.2×실효깊이1**이다. 표시 F625 계열은 내경5·외경16·총폭5·플랜지18×1이다. 고정 지지축은 팔 쪽에 남고 캡은 손과 함께 회전한다. 실제 베어링의 축방향 구속·끼움·스페이서·회전저항은 별도 설계·실측 대상이다.

바깥 캡 귀와 요크 브리지는 **X축 M3 통과홀2개(Ø3.4)**로 묶는다. 두 홀 중심은 **Y90, Z310/320**이다. 브리지에는 **5.8×5.8×축깊이2.2 사각너트 홈**, 캡 바깥에는 **Ø6.4×실효깊이2.2 나사머리 홈**을 둔다. 캡+브리지 체결 스택과 너트 실제 두께를 확인한 뒤 볼트 길이를 정한다. 소켓/사각너트 회전방지·포획과 공구 접근이 확인된 구매 확정 규격은 아니다.

손바닥 앞뒤 목의 체결은 X=좌-170/우+170·Z310/320의 **Y방향Ø3.4 통과홀2개**다. 목의 앞뒤 외면Y11~69 사이 스택은58mm이며 이 목 볼트에는 별도 머리/포획너트 홈이 없다. 외부 머리·너트·와셔와 필요한 나사 돌출을 더해 볼트 길이를 실측한다. 맞춤핀 소켓은 X=좌-160/우+160·Z311/319, Ø4.4의 양쪽3.2mm 깊이 블라인드 시험 형상이다. Ø4×6 느슨한 핀은 손당2개, 양손4개다. 앞뒤 손바닥은 이 핀·목 볼트로 맞추고, 바깥 베어링 캡은 별도의 X방향 두 나사로 분리한다. 베어링 캡을 분리할 수 없게 접착하는 조립을 전제로 하지 않는다.

## 조립 순서와 출력 분할

1. **베이스:** 트레이3개·뚜껑3개와 전후 연결판4개를 정렬키·M3 체결로 조립한다. 전장·스피커·케이블 접근 후 서비스 뚜껑을 닫는다. 접착은 베이스 맞댐선의 선택 보강이다.
2. **J1·J2:** 몸체의 J1 케이스를 고정하고 출력 혼에 Yaw 터릿을 연결한다. 터릿 안 어깨 케이스·고정 지지축은 J1과 함께 움직인다. J2 출력 혼과 반대편 베어링을 팔의 Ø88 캡에 맞추고 위 브리지 두 M3로 앞뒤 팔을 묶는다. 어깨의 구체 치수는 P4에서 유지한 구조지만 **출력은 P5 폴더의 새 팔**을 사용한다.
3. **J3 고정측:** 팔의 손목 앞뒤 코어를 열고 X축 서보 케이스·고정 지지축·레일을 맞춘다. 실제 플랜지 나사와 케이블 경로를 확인한 뒤 코어 앞뒤 체결을 한다. 고정 코어를 회전 손과 하나로 묶지 않는다.
4. **J3 안쪽 출력측:** 바깥 베어링 캡을 열어 둔 상태에서 서보 출력축·혼과 요크의 안쪽 캡을 맞춘다. 중심 나사·혼의 완전 체결·공구 접근을 확인한다. 실제 혼과축의 고정이 먼저다.
5. **손바닥:** 앞·뒤 손바닥을 Ø4×6 맞춤핀2개로 정렬하고 목의 두 M3로 체결한다. 조명·확산판·케이블 공간과 볼트 끝이 닿는지 확인한다. 기존 긴 볼트 시험값을 새 체결부에 일괄 적용하지 않는다.
6. **바깥 베어링 캡:** 베어링을 분리 캡에 넣고 고정 지지축과 동축으로 맞춘 뒤 캡을 마지막에 닫는다. Y90/Z310·320의 X축 두 M3와 너트 홈으로 요크 브리지에 체결한다. 축 이탈 방지와 스페이서가 정해지기 전 하중용 최종 조립으로 보지 않는다.
7. **수동·CAD 확인:** 전원 없이 각 관절의 걸림·간격·배선 굽힘을 먼저 확인한다. CAD는 각 축을 개별±10°→0°로 시험한 뒤 부모 Yaw·Pitch의 누적 자세에서 Roll이 따라 움직이는지 확인한다. 실물 PWM·전력 시험은 별도다.

출력 수량은 **29종·총32개**다(손 맞춤핀1종을4개, 나머지각1개). `geometry_P5_parts.json`의 구조물28개와 핀1종을 `P5/print/manifest.json`과 대조하고 원형/방향STL·3MF의 해시87개와 수량을 확인해 [P5 출력 목록](../P5/PARTS.md)을 생성했다. 최대 출력 높이는 약106.99mm다. P5 전용 STL·방향 STL·3MF를 사용하고 P4의27종/30개와 섞지 않는다. 3MF는 모델·좌표 배치이며 재료/공정 프리셋·서포트·브림·G-code 생성 결과와 구별한다. X1 Carbon의 정적판 크기 검사도 실제 슬라이싱·출력 성공을 대신하지 않는다.

## SolidCraft에서 실제 관절 선택·재생

1. P5 편집 원본 `fold_wing_v8_P5_RPY.solidcraft`를 연다. P4에는 J3 Pitch가 있고 P5에는 **J3_WRIST_ROLL**이 있으므로 파일과 이름을 확인한다.
2. **조립 → 관절 구동**에서 표의 여섯 조인트를 선택하고 한 축씩+10°/-10°로 바꾼다. 선택한 링크와 하위 링크의 실제 자세 변화를 확인한 뒤0°로 복귀한다.
3. **조립 → 운동 연구**에서 **`P5_SIX_JOINT_RPY_DEMO`**를 선택한다. 생성 설정은120 steps, 각 축별20-step 개별 연구6개를 더해 총7개다.
4. 조인트·Ground·강체 관계·Study와 중립값을 저장하고 새 세션에서 다시 연다. 네이티브 엔진 구동과 데스크톱 GUI에서 각도를 바꾼 확인을 각각 기록한다.

명령 검색 **S**에서도 다음 명령을 사용할 수 있다. `joint.drive`와 `motion.play`는 CAD 자세를 바꾼다.

```text
joint.drive {"joint":"L_J3_WRIST_ROLL","value":10}
joint.drive {"joint":"L_J3_WRIST_ROLL","value":0}
motion.play {"study":"P5_SIX_JOINT_RPY_DEMO","step":0}
```

| 구간 | 조인트 | +10° / -10° / 중립 step |
| --- | --- | --- |
| 0~20 | `L_J1_YAW` | 5 / 10 / 15 |
| 20~40 | `L_J2_SHOULDER_PITCH` | 25 / 30 / 35 |
| 40~60 | `L_J3_WRIST_ROLL` | 45 / 50 / 55 |
| 60~80 | `R_J1_YAW` | 65 / 70 / 75 |
| 80~100 | `R_J2_SHOULDER_PITCH` | 85 / 90 / 95 |
| 100~120 | `R_J3_WRIST_ROLL` | 105 / 110 / 115 |

개별 연구 이름은 조인트 이름 뒤에 `_DEMO`다. 최종 조인트 인자는 생성 후 `P5_files/joint_specs.json`, 운동 연구·각도는 `P5_files/motion_studies.json`과 대조한다. MCP에서는 `joint.list`, `joint.inspect`, `occurrence.properties`, `motion.list`로 여섯 실제revolute·오류/충돌 제약/floating·이동 후 축·중심을 확인한다. `moved:true`만으로 해석식 일치나 실제 하드웨어 동작을 주장하지 않는다. 공식 SolidCraft mechanisms/modeling/checking 가이드와 [명령 참조](https://docs.solidcraft.io/reference/commands.html)를 적용한다.

## 원본 편집과 현재 확인 상태

새 X축 코어·캡·레일·혼 홈·브리지는 SolidCraft 기본 솔리드와 닫힌 스케치 extrusion·절삭·결합 피처 이력을 유지한다. 기존 머리·하부 팔의 기준 외형에는 STEP 기반 피처가 포함된다. 손바닥의 둥근 외곽은 네이티브 스케치와 피처로 이어받는다. 전체 설계가 하나의 치수 매개변수에 자동 종속된 모델이라고 주장하지 않는다.

축 위치·케이스·공차를 바꿀 때는 `build_geometry_P5.py`의 관련 형상과 `build_motion_P5.py`의 조인트 원점을 함께 바꾸고, 네이티브 원본·STEP/STL·manifest·도면·동작 검사를 재생성한다. 이전 개정의 출력이나 QA를 재사용하지 않는다.

| 확인 항목 | P5 현재 상태 |
| --- | --- |
| 사용자 요구·서보 배정 | 확정:6서보·좌우 각Yaw/Pitch/Roll 3DOF |
| X동축 손목·분리 베어링 캡 형상 | 네이티브 생성·저장 완료, 실제 끼움은 미검증 |
| 최종 네이티브 저장·6revolute·7Study·스케치 상태 | 79바디·561타임라인(형상513+그룹이동48)·74스케치dof0,6revolute·7Study,타임라인 오류·경고0 |
| 엔진의 개별 구동·실제 손 표면 Roll | 독립12회±10° 구동과 좌우2개 표면점 Roll 추적 확인. X좌표 변화0,10° 실제 변위 약10.9855mm |
| 엔진의 누적 직렬 변환·Study·중립 복귀·재열기 | 추가 검사 진행 중. 부분 통과를 전체 QA 완료로 보지 않음 |
| P5 STEP/STL·수량·정적 출력 배치 | STEP29종 유효·단일 닫힌 솔리드, 최종 원형/방향STL·3MF 각각29개 폐합·단일연결·방향일관·양체적,29종/32개·87해시·정적배치 독립검사 통과 |
| 선택 간섭·연속 가동 | 새 X동축 손목의 독립 검사 근거 추가 대기, 전체 연속 가동·배선·실물은 미검증 |
| P5 도면·GIF·최종ZIP | 제작 예정/진행 중 |
| 데스크톱 P5 열기·각도 구동 | 미확인. 이전 P4의 열기·패널 확인을 P5 결과로 사용하지 않음 |
| 현품 서보 실측·실제 슬라이싱/출력·PWM·부하·연속 가동 | 미검증 |

완료 근거가 생성되면 이 표를 P5 검사 경로·실제 수치로 갱신한다. 선택 각도의 간섭이0이어도 전 범위·복합 연속 운동·케이블·재료 변형과 하중의 검증은 남는다.

출력 메시 이력은 [P5 출력 안내](../P5/PRINT_ASSEMBLY.md#출력-메시-검사와-확인-범위)에서 구별한다. 최초 직접 STL의 수정팔4종이 비폐합하여 같은 STEP을 OCP로 재테셀레이션했고 왼앞 팔의 미세 누락 삼각형1개를 추가 수선했다. [최종 출력 전수검사](P5_geometry_files/print_geometry_QA.json)와 [원표면·체적차 근거](P5_geometry_files/arm_tessellation.json)를 함께 확인한다. 네이티브·STEP 기하와 최종 배포 STL의 검사 결과를 혼동하지 않는다.
