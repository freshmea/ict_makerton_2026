# v8 P4 — 서보 6개·팔당 3DOF와 SolidCraft 구동 설정

> **이전 두 Pitch 구성의 이력이다.** 최신 사용자 기준은 P5의 `Yaw → Shoulder Pitch → Wrist Roll`이며 X동축 손목 서보·하우징으로 개정 중이다. 이 P4의 손목 Pitch 문서·모델·검사 결과를 P5 완료 자료로 사용하지 않는다. [최신 상태](../README.md).

2026-10-23 · 길이 mm · 각도 deg · **검사 완료된 P4 두 Pitch 구성의 이력, 최신 P5 RPY 개정 중**.

P4의 당시 기준은 **왼팔3개 + 오른팔3개 = 서보6개**, `Yaw → Shoulder Pitch → Wrist Pitch`의 직렬 회전3DOF였다. 이전 P3의4모터·팔당2DOF에서 어깨 Pitch의 실제 서보·고정측·회전측을 추가한 이력으로 보존한다. 최신 P5 요구사항의 Wrist Roll을 충족하는 완성본으로 사용하지 않는다.

## 6서보 배정과 운동 체인

```text
몸체·베이스 — Ground
├─ L_J1_YAW → 왼쪽 Yaw 캐리어·어깨 서보 케이스
│  └─ L_J2_SHOULDER_PITCH → 왼쪽 곡선 팔·손목 서보 케이스·손목 고정 지지축
│     └─ L_J3_WRIST_PITCH → 왼쪽 손·손목 구동 혼·손 쪽 베어링 표시
└─ R_J1_YAW → 오른쪽 Yaw 캐리어·어깨 서보 케이스
   └─ R_J2_SHOULDER_PITCH → 오른쪽 곡선 팔·손목 서보 케이스·손목 고정 지지축
      └─ R_J3_WRIST_PITCH → 오른쪽 손·손목 구동 혼·손 쪽 베어링 표시
```

| 서보 배정 | 고정하는 케이스 | 출력축·혼이 구동하는 쪽 |
| --- | --- | --- |
| 왼쪽·오른쪽 J1 Yaw 각 1개 | 몸체·베이스 | 해당 팔의 Yaw 캐리어와 그 위의 어깨·팔·손 전체 |
| 왼쪽·오른쪽 J2 Shoulder Pitch 각 1개 | 해당 Yaw 캐리어 | 해당 곡선 팔과 그 위의 손목·손 전체 |
| 왼쪽·오른쪽 J3 Wrist Pitch 각 1개 | 해당 곡선 팔의 손목 코어 | 해당 손 외장 전후·맞춤핀·구동 혼 |

P3에서 상부 손 관절에 쓰던 `L_J2_PITCH`, `R_J2_PITCH`의 역할은 P4의 **`L_J3_WRIST_PITCH`, `R_J3_WRIST_PITCH`**로 이동한다. 새 J2는 베이스 가까운 어깨 축이다. 이름만 바꾸고 기존 두 축을 계속 사용하는 구성과 혼동하지 않는다.

운동 링크의 occurrence 이름은 좌우 각각 `P4_L_YAW_CARRIER:1`, `P4_L_ARM:1`, `P4_L_HAND:1`과 `P4_R_YAW_CARRIER:1`, `P4_R_ARM:1`, `P4_R_HAND:1`이다. 정확한 바디 배정은 최종 생성된 `P4_files/group_mapping.json`과 대조한다.

각 링크 안에서 함께 움직이는 부품은 rigid 관계로 묶는다. 고정 케이스와 그 서보의 출력 혼은 서로 다른 링크에 배정한다. 어깨의 반대편 고정 지지축은 Yaw 캐리어 쪽에, 손목의 고정 지지축은 곡선 팔 쪽에 남아야 한다. 팔·손을 Ground하거나 케이스와 출력측을 하나의 rigid 묶음으로 합치면 의도한 회전이 잠긴다. Browser의 폴더 부모·자식 관계와 운동 조인트의 부모·자식 관계는 별개다.

베어링 외형을 한 바디로 표현한 경우에는 내륜·외륜·전동체의 상대 회전까지 해석한 모델로 보지 않는다. 표시 바디가 어느 링크를 따라가는지는 P4의 부품 배정 기록과 함께 확인한다.

서비스 조립은 **어깨 앞 회전 캡/팔 절반을 열기 → 고정 코어 앞 개구로 서보 케이스 넣기 → 레일의 플랜지 홀로 케이스 고정 → 실제 혼과 중심 나사 조립 → 뒤 베어링·고정 지지축 정렬 → 팔 앞뒤 브리지 볼트 체결** 순서로 검토한다. 케이스는 개구로 통과하더라도 실제 플랜지와 케이블이 같은 경로를 통과하는지, 공구가 각 나사에 접근하는지는 현품으로 확인해야 한다.

브리지 바깥면 사이 축방향 길이는 Y11~69의 **58 mm**이며, 이 중 출력 재료는28.9×2=57.8 mm, 가운데 릴리프는0.2 mm다. 위쪽 팔의 기존Y40 분할면이 만나므로 브리지 릴리프를 없애려고 두 팔 절반을 억지로 압축하지 않는다. 머리/너트 좌석이 각각2.7 들어가므로 볼트 길이는 좌석과 실제 너트·와셔 스택을 대조해 정한다. 기존 손의 M3×65 시험 규격을 새 어깨에 자동 적용하지 않는다. 새 어깨의 포획 너트가 실물에서 회전·이탈하지 않는지, 볼트 끝이 회전부·배선에 닿지 않는지도 별도 확인한다.

## 회전 조인트 6개의 설계 설정

X는 좌우, Y는 앞뒤, Z는 위쪽이다. 표의 원점·축은 **여섯 각도가 모두 0°인 중립 자세의 world 좌표**다. 신규 어깨 높이 Z180은 현재 설계 기준이며, 실제 서보 수납·회전 여유 확인에 따라 개정될 수 있다.

| 조인트 | 부모 → 자식 링크 | 원점 XYZ | 초기 회전축 | 저장 중립 | CAD 임시 제한 |
| --- | --- | --- | --- | --- | --- |
| `L_J1_YAW` | 몸체 → 왼쪽 Yaw 캐리어 | `[-275,40,130]` | `[0,0,1]` | 0° | -15°~+15° |
| `L_J2_SHOULDER_PITCH` | 왼쪽 Yaw 캐리어 → 왼쪽 팔 | `[-275,40,180]` | `[0,1,0]` | 0° | -15°~+15° |
| `L_J3_WRIST_PITCH` | 왼쪽 팔 → 왼쪽 손 | `[-220,40,315]` | `[0,1,0]` | 0° | -15°~+15° |
| `R_J1_YAW` | 몸체 → 오른쪽 Yaw 캐리어 | `[275,40,130]` | `[0,0,1]` | 0° | -15°~+15° |
| `R_J2_SHOULDER_PITCH` | 오른쪽 Yaw 캐리어 → 오른쪽 팔 | `[275,40,180]` | `[0,1,0]` | 0° | -15°~+15° |
| `R_J3_WRIST_PITCH` | 오른쪽 팔 → 오른쪽 손 | `[220,40,315]` | `[0,1,0]` | 0° | -15°~+15° |

초기 +Y는 좌우 모두 같은 world 방향이지만, P4에서는 이 축을 부모 링크에 붙인 **local Y**로 유지한다. J1을 돌리면 J2·J3의 축 방향과 원점도 따라 움직인다. J2를 돌리면 J3 원점과 손목·손 위치가 팔과 함께 움직인다. J2와 J3가 초기 자세에서 평행해도 서로 떨어진 원점에서 독립적으로 회전하는 두 자유도다.

J1=θ일 때 초기 +Y축은 world 방향 `[-sinθ,cosθ,0]`으로 돌아간다. 초기 J3 원점 W, 어깨 원점 S에 대해 어깨 Pitch=φ를 적용한 손목 위치는 먼저 `S + Ry(φ)(W-S)`로 계산하고, 이어 J1 원점 B 주위에 `B + Rz(θ)(…-B)`를 적용한다. J3의 자체 회전은 이때 이동한 손목 축을 기준으로 한다. 자식 관절을 매번 원래 world Y축이나 원래 원점에 다시 고정하면 직렬 체인이 깨진다.

양의 각도는 오른손 법칙을 따른다. 좌우의 같은 +각도가 같은 시각적 제스처를 뜻하지는 않는다. 서보 채널 번호·전기적 방향·PWM 오프셋은 **미정**이며 CAD 각도와 별도로 보정한다. 0°는 저장된 조립 자세로, 실물 서보의 1500 μs 또는 90° 명령을 뜻하지 않는다.

**±15° 제한과 ±10° 시험은 CAD 동작 확인용이다.** 실제 서보 허용각·토크·배선·간섭·안전한 가동 범위를 확정한 값이 아니다. 실물 한계와 충돌 없는 범위는 별도 시험한다.

## 편집 원본을 수정할 때

새 어깨는 SolidCraft의 실린더·박스·스케치 extrusion·절삭·결합 피처 이력을 유지한다. 기존 머리·팔의 기준 외형은 P2에서 이어받은 STEP 형상이며, P4에서 팔 하부 절삭과 어깨 캡·브리지 피처를 추가했다. STL만 수정하는 방식과 구별한다.

현재 축 배치는 위 표의 Z180을 기준으로 한다. `p4_shoulder_z` 같은 노출 매개변수가 모든 하드웨어·서비스 개구·조인트 좌표까지 하나로 연결된 것은 아니다. 축 위치를 바꾸려면 `build_geometry_P4.py`의 관련 형상과 `build_motion_P4.py`의 회전 원점·운동 설정을 함께 개정하고, STEP/STL·출력 manifest·도면과 구동 검사를 다시 생성한다. 하나의 치수만 바꾼 뒤 이전 모션이나 출력 패키지를 그대로 재사용하지 않는다.

## 조립과 최초 구동 순서

1. 베이스 트레이·뚜껑·연결판을 조립하고 몸체 쪽 J1 서보 케이스를 고정한다. 베이스·머리·전장 배치 영역은 Ground 기준을 따라야 한다.
2. 좌우 J1 출력측에 각각 Yaw 캐리어를 연결하고 새 J2 어깨 서보 케이스를 캐리어에 고정한다. 어깨 케이스가 몸체에 남아 버리면 J1 회전 체인이 끊긴다.
3. J2 출력 혼을 곡선 팔의 회전측과 연결하고 반대편 지지를 맞춘다. 새로운 어깨 하우징·캐리어의 혼 규격, 베어링 유지·이탈 방지, 볼트·인서트 치수는 P4 형상과 현품을 대조한다. 미확정 치수는 **실측 전**이다.
4. 곡선 팔의 상부 코어에 J3 서보 케이스와 고정 지지축을 조립한다. 손의 구동 혼과 앞 커버·브리지·뒤 커버는 함께 회전한다. 기존 손 체결 시험안은 [손 안내](HANDS_NATIVE.md)를 따른다.
5. 전원 없이 각 인터페이스를 수동으로 확인한다. 고정 나사 접근, 서보 혼 중심 나사, 배선 굽힘, 어깨·손목 베어링의 이탈 방지와 회전 저항을 확인한다. 억지 끼움이나 모터 토크로 간섭을 넘기지 않는다.
6. SolidCraft에서는 먼저 J1만, 다음 J2만, 마지막 J3만 시험하고 모두 0°로 돌린다. 이후 J1·J2를 함께 움직여 자식 J3 원점·축·손이 따라오는지 확인한다. 실물 PWM 시험은 전원·신호·방향 보정 후 별도로 한다.

신규 어깨의 체결 상세와 출력 분할은 P4 도면·출력 목록의 최종값을 사용한다. 이전 P2/P3의 전체 출력 수량과 치수를 P4 승인값으로 옮겨 적지 않는다. 접착만으로 구동 하중을 받는 관절을 확정하지 않으며, 하중을 전달하는 혼·축·볼트·베어링 구조를 별도로 확인한다.

## SolidCraft에서 움직이기

1. [P4 `.solidcraft`](../cad/fold_wing_v8_P4_6servo.solidcraft)를 연다. P3에는 네 조인트만 있고 STEP에는 이 운동 연구가 없으므로 파일을 구별한다.
2. **조립 → 관절 구동**에서 위 여섯 이름을 확인한다. 선택한 축을 +10° 또는 -10°로 바꾸고 해당 링크와 자식 링크의 실제 위치 변화를 본다. 시험 뒤 0°로 복귀한다.
3. **조립 → 운동 연구**에서 **`P4_SIX_JOINT_DEMO`**를 선택한다. 각 축 0° → +10° → -10° → 0° 순차 데모의 최종 타임라인·키프레임은 저장 파일과 생성 기록을 기준으로 확인한다.
4. 다른 이름으로 저장할 때 조인트·Ground·rigid 관계·Study와 중립값이 유지되는지 새 세션에서 다시 연다.

명령 검색 **S**에서도 다음 명령을 사용할 수 있다. `joint.drive`와 `motion.play`는 현재 CAD 자세를 바꾼다.

```text
joint.drive {"joint":"L_J2_SHOULDER_PITCH","value":10}
```

```text
joint.drive {"joint":"L_J3_WRIST_PITCH","value":-10}
```

```text
motion.play {"study":"P4_SIX_JOINT_DEMO","step":0}
```

생성기의 `P4_SIX_JOINT_DEMO`는 **120 steps**로 설정한다. 다른 축을 0°로 유지하면서 아래 순서로 한 축씩 움직인다. 축별 20-step Study 여섯 개는 해당 조인트 이름 뒤에 `_DEMO`를 붙인다. 이는 생성 설정이며 최종 저장·재생 성공은 QA 기록으로 확인한다.

| 구간 | 조인트 | +10° / -10° / 중립 복귀 step |
| --- | --- | --- |
| 0~20 | `L_J1_YAW` | 5 / 10 / 15 |
| 20~40 | `L_J2_SHOULDER_PITCH` | 25 / 30 / 35 |
| 40~60 | `L_J3_WRIST_PITCH` | 45 / 50 / 55 |
| 60~80 | `R_J1_YAW` | 65 / 70 / 75 |
| 80~100 | `R_J2_SHOULDER_PITCH` | 85 / 90 / 95 |
| 100~120 | `R_J3_WRIST_PITCH` | 105 / 110 / 115 |

재현 생성기는 [build_motion_P4.py](build_motion_P4.py)다. 정확한 최종 조인트 인자는 `P4_files/joint_specs.json`, 실행 명령은 `motion_P4.json`에 기록한다. 형상 생성·구동 검사·도면 렌더링은 각각의 단계로 구분하며, P3의 4축 검사 기록을 P4 결과로 복사하지 않는다.

MCP/CLI에서는 `joint.list`, `joint.inspect`, `occurrence.properties`, `motion.list`를 확인한다. `moved:true`와 실제 위치·축 변화를 함께 확인하며 `errors`, `conflicts`, `floating`이 비어 있어야 한다. 이 절차는 적용한 공식 `solidcraft-mechanisms`·`solidcraft-checking` 가이드와 [SolidCraft 명령 참조](https://docs.solidcraft.io/reference/commands.html)를 따른다.
