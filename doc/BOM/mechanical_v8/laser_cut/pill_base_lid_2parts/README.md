# 베이스 뚜껑 레이저 커팅 — 2분할

`PILL_BASE_LID_1/2/3`의 조립 형상을 합친 다음 **전체 중앙 X=0에서 좌우 두 조각**으로 나눴다. 원래 3분할선 X=±106.666667은 제거했다. 원본 STL/STEP은 변경하지 않았다.

## 가공 파일

| 파일 | 용도 | 외형 크기 |
| --- | --- | --- |
| `PILL_BASE_LID_LEFT_320x200.dxf` | 좌측 1개 | 320 × 200 mm |
| `PILL_BASE_LID_RIGHT_320x200.dxf` | 우측 1개 | 320 × 200 mm |
| `PILL_BASE_LID_BOTH_320x410.dxf` | 위 두 조각을 한 판에 배치, 사이 간격 10 mm | 320 × 410 mm |
| `reference/PILL_BASE_LID_MERGED_640x200.dxf` | 합친 원형 확인용, 분할선 없음 | 640 × 200 mm |

**개별 파일 좌우 각 1개 또는 BOTH 파일 1개 중 하나만 사용한다.** BOTH와 개별 파일을 모두 가공하면 중복 수량이 된다. 좌우를 구별할 때는 `preview.png`의 상면도를 따른다. 각각의 DXF 원점은 해당 배치의 왼쪽 아래이며, 오른쪽 조각을 뒤집거나 미러링하지 않는다.

## 단위와 재료

- **mm, 1:1, 배율 100%, 원본 기준 판 두께 4 mm.** DXF는 2D 커팅선이며 두께는 재료에서 선택한다.
- 레이저 절단 폭(kerf) 보정은 **0**이다. 실제 재료·장비 시험값으로 가공 프로그램에서 보정한다.
- 외형 R45, 원형 체결 구멍 Ø3.4 × 6개, 사각 개구부 64×24 × 2개와 45×25 × 1개를 유지한다.
- `CUT_INNER`(빨강)는 내부 구멍, `CUT_OUTER`(흰색/검정)는 외곽이다. **두 레이어 모두 절단**하며 내부를 먼저 절단한다. 각인은 없다.
- 닫힌 LWPOLYLINE과 CIRCLE만 사용한다. 원호는 폴리라인 bulge로 저장하며, 문자·치수선·해치·스플라인·중복 절단선을 넣지 않았다.

## 조립과 확인 범위

원래 3개 트레이 위에 두 뚜껑을 올리는 구성이다. 체결 구멍 위치를 유지했으며 새 이음부에 탭·연결판·체결 구멍을 추가하지 않은 **직선 맞댐**이다. 기존 중앙 사각 개구부의 왼쪽 가장자리는 새 분할선에서 **2.5 mm** 떨어져 있다. 해당 가장자리와 중앙 이음부 지지 상태는 현물에서 확인한다.

최대 가공 영역은 아직 제공되지 않았으므로 장비 적합 여부는 확인하지 않았다. 개별 파일은 최소 320×200 mm, BOTH는 최소 320×410 mm의 유효 영역과 장비별 여유가 필요하다. 실제 레이저 커팅·체결 시험은 수행하지 않았다.

STEP의 상면에서 원·모서리·사각 개구부를 확인하고, 원형을 나타내는 유리 B-spline을 원과 원호로 복원했다. DXF 재입력으로 단위·외형 범위·폐합·구멍 수·중복 여부를 검사했다. 두 조각을 조립 좌표로 되돌린 형상이 통합 형상과 일치하고 현재 지정 STL의 상면과도 맞는지 비교했다. 수치와 입력 파일 SHA-256은 `verification.json`에 있다.
