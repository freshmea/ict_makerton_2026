## 미확보 자료 및 보완

- S06: SunFounder 위키 연결 시간 초과. 제조사 제품 페이지 S05와 IC 데이터시트 S01로 보완했다.
- S07~S09: Raspberry Pi HTML 직접 요청 403. 웹 도구로 열람한 핵심 사양은 재료 목록에 요약했다. Camera Module 3 PDF는 저장했으나 Camera V2 독립 제조사 PDF는 확보하지 못했다.
- S13: HobbyKing 직접 요청 403. S14 판매처 자료는 보조 자료이며 제조사 원본 사양서가 아니다.
- S18: SKY HOLIC 사이트 TLS 인증서 검증 실패. 인증서 검증을 끄지 않았다. 해당 배터리 제품 데이터시트는 확보하지 못했다.
- 마이크(B12)는 모델 미정으로 정확한 데이터시트를 찾지 못했다. UGREEN 30143(S28)은 보유 어댑터와 동일 모델로 확인되지 않은 참고 제품이다.
- LED(B15)의 IC 품번은 미정이다. S25는 Worldsemi WS2812B V5 문서의 모듈 업체 보관본이며 현품 확정 사양서가 아니다. S26·S27은 Adafruit 호환 계열 일반 참고자료다.
- BA-R9(S23·S24)는 제조사 제품 페이지와 공식 JPG 사용설명서를 저장했다. 별도 PDF 데이터시트는 미확보다.
- S30: Analog Devices 제품 HTML 요청이 연결 종료로 실패했다. 같은 제조사의 MAX7219/MAX7221 데이터시트 S29는 확보했다.
- 터치 센서(B17)는 IC 품번 미정이다. S31·S32는 TTP223 후보 IC 제조사 자료이며 현품 확정 사양서가 아니다. LED 매트릭스(B16)는 IC 표기로 분류했으며 모듈 회로도·LED 품번은 미확보다.
- Wi-Fi 동글 및 커넥터·케이블은 품번 미정이다. 임의 제품 데이터시트로 대체하지 않았다.

## 자료 해석

IC 데이터시트는 HW-411 또는 SunFounder 보드 전체의 정격을 보증하지 않는다. Spektrum 자료는 다른 제조사 LiPo의 일반 참고자료다. Jetson 가이드는 과거 r32-2 배포본이므로 현품의 보드 리비전과 대조한다. 정부 조회 HTML은 스크립트 의존 내용이 있을 수 있으므로 원문 브라우저 조회를 병행한다. HTML은 본문 응답만 저장했고 CSS·이미지 등 외부 자원은 포함하지 않았다.

원문 URL, 최종 URL, UTC 다운로드 시각, HTTP 상태, SHA-256과 오류 상세는 [sources.json](sources.json), 무결성 및 PDF 검사 결과는 [verification.json](verification.json)에 기록했다.
