# SKY HOLIC Balancer Guard V 연결 안내

## 현재 판단

사진에서 SKY HOLIC **Balancer Guard V**라는 모델명을 확인했다. 디바이스마트에도 같은 제품명이 등록되어 있다. 당시 직접 사용·분해한 기록은 Lithium Solution II라는 별도 충전기와 Balancer Guard V를 구분하고, 밸런서를 충전기의 배터리 출력과 배터리 사이에 연결하는 장치로 설명한다. 따라서 현재 확보한 근거로는 **단독 충전기가 아닌 외장 밸런서로 판단**한다. 제조사 원본 설명서와 현품의 입력/출력 정격은 아직 확보하지 못했다.

**12V 어댑터를 이 장치의 바나나 플러그 또는 배터리 3핀 단자에 직접 연결하지 않는다. 사진에 나온 세 물품만으로는 충전 구성이 완성되지 않았다. 별도 LiPo 충전기가 필요하다.**

## 필요한 연결 구조

다음은 기능 관계를 설명한 개념도이며, 현품 단자의 핀 순서나 실제 연결 순서를 확정한 도면이 아니다.

```text
12V 어댑터
   │ (충전기의 입력 정격·극성·소비전력과 맞을 때)
   ▼
LiPo 2S 지원 충전기 [추가 필요]
   │ 배터리 충전 출력 + / -
   ▼
Balancer Guard V의 빨강 / 검정 바나나 플러그
   │
   ▼
핀 배열이 검증된 전용 2S 변환 하네스
   │
   ▼
7.4V LiPo 배터리의 셀 탭/밸런스 단자
```

사진의 빨강 바나나 플러그는 충전기 출력 +, 검정 바나나 플러그는 출력 -에 연결하는 계통으로 판단한다. **12V 전원 입력용으로 간주하지 않는다.** 사진 아래쪽 흰색 하네스는 배터리 연결 계통으로 보이나, 커넥터 핀 수·배선·2S용 여부가 사진에서 충분히 확인되지 않았다. 배터리의 3핀과 외형이 맞는다고 곧바로 꽂거나, 다핀 단자의 일부 핀에 끼우지 않는다. 제조사 배선도 또는 실물 측정으로 셀별 연결점을 대조해야 한다. 구형 제품의 변환 하네스는 현대의 일반 JST-XH 배열과 같다고 가정하지 않는다.

이 모델의 정확한 배터리 주 전원선 처리 방식과 접속 순서는 제조사 설명서가 확보되기 전에는 확정하지 않는다. 주 전원선의 별도 병렬 연결이나 임의 배선은 제안하지 않는다. 밸런서가 내장된 새 충전기를 사용할 경우에는 해당 충전기 설명서대로 배터리를 직접 연결하는 구성이 가능하며, 이 구형 밸런서를 중간에 추가해야 한다고 가정하지 않는다.

## 충전 조건

- 배터리 라벨은 **7.4V 2200mAh LiPo**이며 일반적인 2S 구성으로 추정한다. 실제 셀 구성과 상태를 확인한 뒤 충전기의 LiPo/2S 모드를 사용한다. 일반 LiPo는 셀당 4.2V, 2S 전체 8.4V가 충전 상한이다. LiHV나 NiMH 모드를 선택하지 않는다.
- 허용 충전전류는 해당 배터리 제조사 규격으로 결정한다. 2200mAh라는 용량만으로 2.2A 충전을 허용한다고 단정하지 않는다.
- 기존 어댑터는 12V 1.5A 18W다. 충전기의 입력 전압 범위와 필요 전력, 잭 규격·극성을 모두 만족할 때만 충전기 입력 전원 후보가 된다. 충전기 모델이 정해지기 전에는 이 어댑터의 적합성도 미정이다.
- 퓨즈는 충전 전류·전압 제어를 대신하지 않는다. 사진의 주황색 퓨즈 정격은 사진만으로 확정하지 않는다. LM2596 가변 강압 모듈도 LiPo 충전기를 대신하지 않는다.
