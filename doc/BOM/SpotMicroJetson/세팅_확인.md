# SpotMicroJetson 원본 설정 확인

기준: Road-Balance/SpotMicroJetson 커밋 `2235c77a93e86d04dec2e03c6306ba2c06d454ce`, 공개 BOM 및 원본 강좌의 자동자막. 사용자 장치의 현재 설정값을 측정한 문서가 아니다.

## 전원 설정: 서보 6V, Jetson 5V

저장소 README의 Electronics 문단은 **Jetson 5V / 서보 구동부 6V**로 설명한다. 12강은 7.4V 배터리에서 LM2596으로 6V를 만들어 서보 보드 외부 전원 V+에 넣는 과정을 설명한다. 앞선 대화에서 제시한 배터리 직결 예시는 이 강좌의 구성을 재현한 설명이 아니었으므로, 이 프로젝트를 기준으로는 아래와 같이 정정한다.

```text
7.4V LiPo 배터리 (일반 2S 완충 시 8.4V)
  ├─ LM2596 출력 6.0V → PCA9685 #1 V+ → 서보 그룹
  ├─ LM2596 출력 6.0V → PCA9685 #2 V+ → 서보 그룹
  └─ Jetson용 5.0V 전원 경로 → Jetson Nano
```

첫 두 갈래의 강압·외부 전원 연결은 12강 설명에 근거한다. 마지막 5V 경로는 README의 Jetson 동작 전압과 BOM의 LM2596 3개를 함께 정리한 기능도다. **세 번째 모듈의 실제 배선과 단자 위치까지 이 도식으로 확정하지 않는다.** 현품 사진에서는 LM2596 1개만 보이며 선이 분리되어 있어 어떤 갈래를 담당하는지, 출력이 5V인지 6V인지 측정해야 한다.

| 근거 | 확인한 내용 | 자막 파일 / 원문 |
| --- | --- | --- |
| README Electronics | Jetson 5V, 서보부 6V, LM2596 사용 | [README](repo/README.md) |
| 12강 08:18~09:42 | VCC와 서보 외부 전원 V+ 구분, 사용 보드의 V+ 최대 6V 설명 | [12강 자동자막](transcripts/12_power.txt), [영상](https://www.youtube.com/watch?v=AUtIKKJltyg&t=498s) |
| 12강 11:49~13:48 | 7.4V 2200mAh 배터리, LM2596 출력전압을 멀티미터로 확인하며 6V로 조정 | [영상](https://www.youtube.com/watch?v=AUtIKKJltyg&t=709s) |
| 12강 18:25~18:46 | 배터리 → DC 컨버터 → 6V → 모터 드라이버 외부 전원 경로 | [영상](https://www.youtube.com/watch?v=AUtIKKJltyg&t=1105s) |
| 공개 BOM | LM2596 3개, PCA9685 2개, CLS6336HV 12개 | [XLSX](Spot_Micro_BOM.xlsx) |

12강 16:55 부근은 강압 회로에 필요한 입력/출력 전압 차이도 언급한다. 배터리 전압이 내려가면 LM2596이 6V를 계속 유지하지 못할 수 있다. 따라서 목표 6V 설정과 배터리 전 구간의 실제 안정 출력은 별도 검증 항목이다. 모듈·단자·배선의 전류 용량과 발열도 별도로 확인한다.

원본 README에는 `PCA9658` 및 `7.9v LiPo`라는 표기가 있으나 BOM·코드는 PCA9685, BOM·12강은 7.4V 배터리를 가리킨다. 오기로 추정하되 원문 파일은 수정하지 않았다. **7.9V를 배터리 충전 목표로 해석하지 않는다.** 이 강좌의 구동 전원 설명은 12V 어댑터 직결 충전을 허용하는 근거도 아니다.

## I2C와 보드 주소

- 코드 버스: `busio.I2C(board.SCL_1, board.SDA_1)`.
- 코드 주석의 버스 이름: Jetson **Bus 0**. 물리 핀 **27=SDA, 28=SCL**. 원본 12강 19:38~20:13과 [예제 주석](repo/JetsonNano/examples/test_servos_cali.py)에 근거한다.
- 두 보드 주소: **0x40 / 0x41**. 두 번째 보드의 주소 설정은 12강 20:18~20:46 설명과 코드에 근거한다. 실제 보드의 주소 패드/납땜 상태를 확인해야 한다.
- 12강 19:16 부근은 로직 전원에 Jetson 물리 핀 2와 GND 6을 썼다고 설명한다. 이는 원본의 배선 설명이며, 보유 보드의 SDA/SCL 풀업 전압까지 검증한 결과가 아니다. Jetson 신호 전압과 보드의 풀업 연결을 확인한 후 재현해야 한다. **서보용 6V V+와 로직 VCC를 혼동하지 않는다.**

## 서보 PWM·각도 보정

| 항목 | 원본 수정판 `servo_controller_fix.py` 값 | 해석 |
| --- | --- | --- |
| PCA9685 주소 | 0x40, 0x41 | 보드 2개 |
| PWM 주파수 | 두 보드 모두 **60Hz** | 저장소 수정판 값이며 모든 서보의 보편 정격을 뜻하지 않음 |
| 펄스 폭 | **460~2440µs** | 이 수정판의 보정값. 현품 제조사 정격·기계 한계 확인 없이 최대 범위를 바로 적용하지 않음 |
| 모터 인덱스 | 0~11 | 다리당 3개, 4개 다리 |
| 중립 오프셋 | `[180,90,90,1,90,90,180,90,90,1,90,90]` | 해당 조립 방향과 혼 위치에 맞춘 값이며 개별 캘리브레이션 필요 |

근거: [수정판 코드](repo/JetsonNano/servo_controller_fix.py), [18강 자동자막](transcripts/18_calibration.txt). 15·18강의 자동자막에는 500~2500µs 등 사양 설명도 보이므로 **강의의 사양 설명과 후속 수정판의 실제 코드 값을 구별**한다.

주의해서 읽을 코드 차이:

- `servo_controller_fix.py`는 첫 보드 채널 0~5, 둘째 보드 채널 6~11을 사용한다. 반면 `examples/test_servos_cali.py`는 각 보드에서 `%6`으로 채널 0~5에 접근한다. 이 두 파일의 배선을 하나로 가정하지 않는다.
- 기존 `servo_controller.py`는 다른 오프셋과 각도 변환식을 사용한다. 수정판과 섞어 적용하지 않는다.
- `test_servos_cali.py`의 `val_list=[90]`와 0~11 모터 입력 등의 조합은 그대로 사용하기 전에 검토가 필요하다. 이번 작업에서는 코드를 보관하고 설정을 읽었으며 실행·수정하지 않았다.

## 설치·실습 순서와 오래된 의존성

원본 강좌는 **Jetson Nano를 사용하되 ROS 없이 진행(w/o ROS)**한다. 준비물 → 3D 부품 → 데스크톱 시뮬레이션/기구학 → 기구 조립 → 전원부 → Jetson 환경 → 모터 제어 → 캘리브레이션 → 보행 순서다. 04강 제목에는 시뮬레이션을 Jetson이 아닌 데스크톱에 구성한다고 명시되어 있다.

저장소에 남은 고정 버전 예: `numpy==1.13.3`, `matplotlib==2.1.1`, `adafruit-circuitpython-servokit==1.3.0`, `adafruit-circuitpython-pca9685==3.3.2`. [의존성 원문](repo/JetsonNano/requirements.txt).

설치 안내에는 `SpotMiroAI/JetsonNano` 오타, `SpotMicroJetson/Core` 등 현재 트리와 맞지 않는 경로가 남아 있다. 해당 명령을 현재 환경에서 검증한 설치 절차로 제시하지 않는다. JetPack/L4T·Python 버전을 확인한 뒤 별도 작업환경에서 재현해야 하며, 이 문서 작성 중에는 패키지를 설치하거나 GPIO에 접근하지 않았다.
