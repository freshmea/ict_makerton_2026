# 대시보드 로그 분석 발표 보강

2026-10-25 KST · 300 Seconds

[Google 프레젠테이션](https://docs.google.com/presentation/d/16-7NiQcdMrxext3BRB5LvivOQ9ZsSl5vnv3RDpJneLw) · [최신 18장 PDF](../../output/pdf/폴드윙버디_발표자료_로그분석_2026-10-25.pdf)

사용자가 직접 편집한 15장 발표를 기준으로 현재 9장 **사회적가치(기대효과)** 바로 뒤에 로그 분석 3장을 추가했다. 추가 위치는 10~12장, 전체는 18장이다. 기존 15장의 내용과 순서는 변경하지 않았다. 읽기 결과의 기존 슬라이드별 텍스트·도형·이미지·메모를 대조해 이를 확인했다. 이미지의 조회용 URL처럼 매번 바뀌는 필드는 비교에서 제외했다.

## 추가한 장표

### 10. 로그 분석 · 쌓인 기록을 학습 흐름으로

시간별·하루·월간 총평 · 집계와 키워드로 작성, 추가 AI 요청 없음

- **시간별 총평:** 하루 24시간을 펼쳐보고 원하는 시간의 기록 확인
- **하루의 기록:** 학습 행동·자리·감정 단서 하루 총평으로 정리
- **한 달의 변화:** 날짜별 흐름을 살피고 학습 지원에 참고

**발표자 메모**

2026-10-25에 배포한 로그 분석 페이지를 소개합니다. 메인 대시보드의 로그 분석에서 실제 기록과 데모를 선택하고 시간·하루·한 달을 조회합니다. 시간별은 선택 시간과 이전 다섯 시간을 보여주며, 24개 시간별 총평에서 상세 구간으로 이동할 수 있습니다. 한국어 총평은 집계 수치와 빈도 키워드의 규칙으로 만들고 추가 AI 호출을 하지 않습니다. 원본 사진 분석·Live 대화의 기존 비용이 없어진다는 의미는 아닙니다. 실제 화면은 보이는 동안60초마다 갱신됩니다. 화면은 배포된 실제 UI에 359일 가상 기록을 표시한 데모이며, 수치가 실제 학습자의 측정값은 아닙니다.

### 11. 14일·12개월 추세로 변화를 비교합니다

진행 중인 기간은 이전 기간의 같은 경과 시간과 비교합니다.

- **일별·월별 흐름:** 최근 14일·12개월 추세
- **세 가지 지표:** 학습·자리·감정 단서
- **총평 상세 보기:** 원하는 날짜·월로 이동

**발표자 메모**

학습 행동·자리비움·긍정/차분 단서의 세 추세선을 최근14일 또는12개월 단위로 살펴봅니다. 표의 총평 보기를 누르면 해당 날짜·월의 상세를 엽니다. 완료 기간은 바로 전 시간·날짜·월 전체와 비교하고, 오늘10:30처럼 진행 중인 기간은 어제00:00~10:30처럼 같은 경과 시간과 비교합니다. 실제 기록의 잘린 마지막 시간은 원본 관찰을 다시 집계하며 평균을 비례 배분하지 않습니다. KST 기준이며 표본이 부족하면 증감 평가를 보류하고 대시를 표시합니다. 증감의 단위는 %p입니다. 화면은 실제 배포 UI의 데모 추세이며 성과 검증이나 학습 향상 실적을 나타내지 않습니다.

### 12. 총평은 관찰 근거와 함께 보여줍니다

학습 행동·자리 상태·감정 단서와 함께 기록의 범위를 확인합니다.

- **보이는 학습 행동:** 읽기·필기·키보드 입력 재석 표본을 기준으로 집계
- **문구 속 감정 단서:** 관찰 문장·키워드로 분류 사람의 실제 감정과 구분
- **기록의 범위:** 미수집·판단 불가를 구분 데이터 커버리지를 함께 표시

**발표자 메모**

지표의 분모와 불확실성을 설명합니다. 카메라 두 대의 최신 기록을 같은 10초 구간 하나로 합쳐 같은 사람을 이중 계산하지 않습니다. 학습 행동 비율은 재석 표본 중 읽기·필기·키보드 입력이 보인 비율입니다. 자리비움 KPI는 관찰된 표본을 분모로 하며 미수집은 별도입니다. 감정 단서 분포는 재석 전체 표본을 분모로 여섯 그룹을 보여주고 감정 단서 없음도 포함합니다. 긍정·차분 KPI/추세선은 단서가 있는 재석 표본만을 분모로 하므로 단서 커버리지를 함께 봅니다. 긍정·활력, 차분·안정, 긴장·어려움, 피로·휴식, 복합, 단서 없음은 관찰 문구·키워드의 문자열 규칙이며 실제 감정 확정이나 눈 LED 표정 기록이 아닙니다. 미수집·실패·판단 불가를 학습 실패나 자리비움으로 자동 평가하지 않습니다. 데모는 메모리에서 별도로 생성하고 실제 관찰·총평 DB에 더미 행을 넣지 않으며 실제 데이터가 없으면 빈 상태로 표시합니다.

### 지표의 분모

| 지표 | 읽는 기준 |
| --- | --- |
| 학습 행동 | 재석 표본 중 읽기·필기·키보드 입력이 관찰된 비율. 내적 집중력·실제 학습 시간의 직접 측정값과 구분 |
| 자리비움 | 관찰된 표본 중 자리비움이 확인된 비율. 미수집은 제외 |
| 감정 단서 분포 | 재석 전체 표본을 분모로 긍정·차분·긴장·피로·복합·단서 없음을 표시 |
| 긍정·차분 KPI·추세 | 감정 단서가 있는 재석 표본만 분모로 사용. 단서 커버리지를 함께 확인 |
| 데이터 커버리지 | 선택 기간에서 이미 지난 10초 구간 중 성공·중복 관찰이 남은 비율 |

카메라 두 대의 관찰은 같은 10초 구간으로 합친다. 진행 중인 기간은 이전 기간의 같은 경과 구간과 비교하고, 표본 부족은 평가 보류로 표시한다. 미수집·판단 불가·자리비움은 구분한다. 감정은 관찰 문구·키워드의 명시적 단서이며 실제 심리상태의 확정이나 로봇 눈 표정 기록이 아니다.

### 화면과 비용 설명

세 장의 화면은 실제 Nano 배포 검증 화면에서 발췌했으며 **DEMO 가상 기록**을 표시한다. 359일 예시와 75.8% 등의 화면 수치는 제품 효과·실제 학습 성과로 발표하지 않는다. 데모는 메모리에서 별도 생성하며 실제 관찰·총평 DB에 더미 행을 삽입하지 않는다. 실제 데이터가 없으면 빈 화면을 유지한다.

**총평 작성 자체는 집계 수치와 키워드 규칙으로 처리하므로 추가 AI 요청이 없다.** 기존 사진 분석·음성 대화의 비용이 없어졌다는 의미는 아니다. 이번 발표 자료 작성 중 새 카메라 분석·AI 추론·장치 제어·서비스 설정 변경은 수행하지 않았다.

## 검수

- 현재 Google 원본의 9장과 10장 사이에 새 3장을 배치하고 기존 15장과의 내용·순서 보존을 대조했다.
- 기존 아이보리·녹색·산호색과 Noto Sans KR을 유지했다. 3행 강조 구조를 복제해 편집했고 스크린샷은 비율을 유지했다.
- 18장 PDF 렌더와 신규 3장 독립 시각 검수를 수행했다. 작은 범례는 편집 가능한 네이티브 텍스트로 확대했다.
- 구조 검사에서 신규 장표 오류는 없었다. 사용자가 작성한 기존 향후 계획 장의 화살표 표기는 유지했다.
