기존 README에 연결된 발표 자료를 직접 채웠다. 기술 보강 후 제품 본문 14장·기술 설명 11장·Q&A용 부록 3장, 총 28장으로 구성했으며, 13개의 저장소 이미지를 사용했다. 텍스트·도형·발표자 메모는 Google 슬라이드에서 수정할 수 있다. 15~25장의 [Rust·Embassy·SBC MA·통신·단계별 구현 설명과 PDF·코드 근거](기술보강_2026-10-24.md)는 별도 문서에 정리했다. [최종 PDF](../../output/pdf/폴드윙버디_발표자료_기술보강_2026-10-24.pdf)도 제공한다.

## 발표의 중심

아이가 목표와 속도를 선택하고 스스로 생각할 시간을 유지하도록 돕는 책상 위 피지컬 AI 학습 동반자다. 기본은 조용한 대기이며, 요청받을 때 짧은 도움을 제공하고 다시 기다린다. 목표·학습 기억·음성·눈 표정·조명·관절을 이 경험에 연결한다.

## 사용할 때의 기준

- 제품 사용 장면과 v6·v7 외관 이미지는 AI 생성 콘셉트다. 실제 조립 시제품의 사진으로 소개하지 않는다.
- P5 이미지는 실제 CAD 렌더다. 최신 구조는 좌우 각 Yaw·Pitch·Roll 3축, 총 6축이다.
- 부품 사진과 대시보드 이미지는 실제 개발 기록이다. 대시보드 표정 미리보기와 실물 LED의 확인 결과를 구분한다.
- 장치 입출력, 요청·정지·기억 경로, 한국어 한 발화와 외부 생성·TTS 연결 시험을 확인했다. AEC·음성 끼어들기, 행동·교재 정확도, 기구 결합·보정, 전원 및 장시간 안정성은 추가 검증 대상이다.
- 실제 학생 인터뷰·학습 효과·수요·매출·전체 제품 완성률을 입증한 수치를 만들지 않았다.
- 진단 대시보드와 Rust 실행판은 별도 운용 경로다. 기능 시연 전 사용할 경로와 장치 점유 상태를 확인한다.

### 28. 발표 근거와 자료의 성격

부록 C  /  아래 경로는 작성에 사용한 로컬 저장소 자료입니다.

**발표자 메모:** 이미지의 출처와 성격을 구분합니다. 제품 사용 장면과 v6·v7 외관은 AI 생성 콘셉트, P5 이미지는 CAD 렌더, 부품 사진과 대시보드는 실제 기록입니다. 교육 효과·수요·정확도·매출 수치는 아직 발표에서 주장하지 않습니다.

**근거:** 근거 저장소: github.com/freshmea/ict_makerton_2026 / 기준일 2026.10.24

## 발표 준비 권장 순서

1. 발표 시간에 맞춰 본문 분량을 조정하고 부록은 질의응답에 활용한다.
2. 팀 역할과 제품명(가칭)을 팀에서 확정한다.
3. 실제 장치에서 확인한 요청·대기·힌트·Stop·기억 조회 경로를 시연하고, 미검증 음성 끼어들기는 라이브 완성 기능으로 소개하지 않는다.
4. 전원·카메라 화각·API 호출 가능 상태를 사전 점검한다. 사진 수집이나 유료 API 호출은 이번 발표 작성 작업에서 실행하지 않았다.
5. 라이브가 불안정하면 확인된 장치 로그·화면·영상으로 설명하고 실제 동작과 경험 예시를 명시한다.
