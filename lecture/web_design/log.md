## claude 에서 Figma 커넥터로 활용한다

---


```text
claude 에서 커넥터를 이용해서 디자인 하는 방식을 수강 중이다. gpt app 이나 codex 에서 같은 방식으로 작업 할 수 있는가?

codex 의 플로그인으로 할 수 있다.

① 생성 프롬프트
 복사
이 Figma Design 파일에 데스크톱 크기의 새 프레임을 만들어줘.
제목·설명·신청 버튼이 있는 강의 카드를 추가하고 Auto Layout을 적용해줘.

② 수정 프롬프트
 복사
방금 만든 카드 제목을 “생성형 AI와 Figma 실습”으로 바꾸고,
신청 버튼 색상을 파란색으로 변경해줘.
```

## 예시 모여스터디

```text
이 Figma Design 파일을 편집해줘.
파일 링크: https://www.figma.com/design/ymNe79de5z2MiFCGwCkQzP/%EB%AA%A8%EC%97%AC%EC%8A%A4%ED%84%B0%EB%94%94-%C2%B7-%EB%AA%A8%EC%9E%84-%ED%83%90%EC%83%89?node-id=0-1&t=3kOuKFaSD0awFmgD-1
대학생이 함께 공부할 모임을 찾는 ‘모여스터디’ 모바일 목록 화면을 만들어줘.
- 모바일 프레임 너비 390px, 상단 제목은 ‘모여스터디’
- 과목 필터: 전체·영어·수학·코딩
- 카드 정보: 모임 제목·일정·장소·모집 인원
- 카드 버튼: ‘모임 자세히 보기’
- 목록과 카드는 Auto Layout 적용
- 회색 와이어프레임으로 만들고 모든 요소를 직접 편집 가능하게 생성
```

## 추가 수정

```text
각 박스에 있는 모임자세히보기 버튼의 fill Container 조건으로 너비를 변경해줘
```

```text
방금 만든 모여스터디 목록 화면에 디자인 스타일을 적용해줘.
- 주요 색상은 보라색, 화면 배경은 아주 밝은 회색
- 카드는 흰색 배경과 16px 모서리
- 카드 내부 여백 20px, 카드 사이 간격 16px
- 제목은 굵게, 일정과 장소는 제목 바로 아래에 배치
- 모집 인원은 강조색으로 표시
- 버튼은 보라색 배경과 흰색 글자로 변경
- 기존 정보 순서는 유지하고 새로운 화면은 만들지 마
```

- 수정 요청 형식

```text
[모바일 목록 화면 링크]에서
[어느 요소]에 [어떤 문제]가 있어.
[디자인 MD의 기준]에 맞게 [무엇을] 수정해줘.
다른 정보의 순서는 유지해줘.
수정 후 무엇이 달라졌는지 한 문장으로 설명해줘.
```
