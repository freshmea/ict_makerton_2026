# 모여스터디 디자인 가이드

이 문서는 모여스터디 모바일 목록 화면에 적용할 공통 디자인 규칙입니다.
기존 정보의 내용과 순서는 유지하고, 아래 규칙을 현재 화면에 적용합니다.

## 1. 색상

- 화면 배경: `#F7F7FA`
- 카드 배경: `#FFFFFF`
- 주요 강조색: `#6C4DFF`
- 기본 글자색: `#17151D`
- 보조 글자색: `#6B6875`
- 구분선: `#E4E2EA`
- 버튼 글자색: `#FFFFFF`

## 2. 글자

- 화면 제목: `24px / Bold`
- 카드 제목: `18px / Bold`
- 본문: `14px / Regular`
- 일정·장소 등 보조 정보: `13px / Regular`
- 모집 인원: `13px / Semibold`
- 버튼 문구: `14px / Semibold`

긴 카드 제목은 최대 두 줄까지 표시합니다. 제목이 길어지면 텍스트와 카드의 높이가 내용에 맞게 늘어나야 합니다.

## 3. 간격

- 화면 좌우 여백: `20px`
- 화면 위쪽 여백: `24px`
- 제목과 필터 사이: `20px`
- 필터 사이 간격: `8px`
- 필터와 목록 사이: `20px`
- 카드 내부 여백: `20px`
- 카드 사이 간격: `16px`
- 카드 내부 요소 사이: `8px`
- 카드 정보와 버튼 사이: `16px`
- 버튼 좌우 안쪽 여백: `16px`
- 버튼 위아래 안쪽 여백: `12px`

## 4. 모서리와 테두리

- 카드 모서리: `16px`
- 버튼 모서리: `10px`
- 필터 모서리: `20px`
- 카드 테두리: `1px solid #E4E2EA`
- 그림자 효과는 사용하지 않습니다.

## 5. 카드 정보 순서

각 스터디 카드는 다음 순서를 유지합니다.

1. 모임 제목
2. 일정
3. 장소
4. 모집 인원
5. `모임 자세히 보기` 버튼

## 6. 필터

다음 과목 필터를 화면 상단에 배치합니다.

- 전체
- 영어
- 수학
- 코딩

선택된 필터는 주요 강조색 배경과 흰색 글자를 사용합니다. 선택되지 않은 필터는 흰색 배경, 기본 글자색, 구분선 색상의 테두리를 사용합니다.

## 7. 버튼

- 버튼 배경은 주요 강조색 `#6C4DFF`를 사용합니다.
- 버튼 문구는 `모임 자세히 보기`로 표시합니다.
- 버튼 문구가 잘리거나 줄바꿈되지 않아야 합니다.
- 문구가 변경되어도 좌우 안쪽 여백이 유지되어야 합니다.
- 버튼 너비는 문구에 맞게 `Hug contents`로 설정합니다.

## 8. Auto Layout

### 화면과 목록

- 스터디 목록 방향: `Vertical`
- 목록의 카드 사이 간격: `16px`
- 목록 너비: 부모 프레임에 맞게 `Fill container`
- 목록 높이: 내용에 맞게 `Hug contents`

### 카드

- 카드 방향: `Vertical`
- 카드 너비: `Fixed Contents`
- 카드 높이: 내용에 맞게 `Hug contents`
- 카드 내부 여백: 상하좌우 `20px`
- 카드 내부 요소 사이 간격: `8px`

### 텍스트와 버튼

- 긴 제목은 최대 두 줄로 표시합니다.
- 제목과 카드 높이는 내용에 맞게 늘어납니다.
- 버튼 너비는 `Hug contents`를 사용합니다.
- 텍스트와 버튼이 서로 겹치지 않아야 합니다.

## 9. Figma 편집 조건

- 텍스트, 필터, 카드와 버튼은 각각 직접 선택하고 편집할 수 있어야 합니다.
- 목록과 카드는 Auto Layout을 유지해야 합니다.
- 화면 전체를 하나의 이미지로 만들지 않습니다.
- 새로운 화면을 추가하지 않고 현재 모바일 목록 화면에만 규칙을 적용합니다.
- 기존 모임 정보와 정보 순서는 임의로 삭제하거나 변경하지 않습니다.


## 11. 완료 후 확인

- 카드 제목이 길어져도 잘리지 않는가?
- 일정과 장소가 제목 바로 아래에 표시되는가?
- 버튼 문구가 모두 보이는가?
- 카드 내부 여백과 카드 사이 간격이 구분되는가?
- 모든 카드에 동일한 간격 규칙이 적용됐는가?
- 텍스트, 카드와 버튼을 각각 선택하고 편집할 수 있는가?
