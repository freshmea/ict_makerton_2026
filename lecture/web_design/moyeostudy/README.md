# 모여스터디 화면 디자인 v1.0

- `design.yaml`: 색상·글자·간격·레이어 구조·Auto Layout 대응 속성·예시 데이터·변경 이력.
- `styles.css`: 실제 HTML에 적용되는 디자인 토큰과 반응형 스타일.
- `index.html`: 로그인·메인·상세의 편집 가능한 코드와 동작 시연. 브라우저에서 파일을 열어 사용할 수 있습니다.
- `image-prompt.txt`: 이미지 생성 요구사항을 기록한 프롬프트. 생성 도구는 내장 image_gen입니다.
- `moyeostudy-concept.png`: 생성 시안 이미지. 코드와 다르게 표현된 부분은 YAML과 CSS를 기준으로 수정합니다.
- `code-preview.jpg`: HTML/CSS를 실제 브라우저에서 렌더링한 정확한 코드 미리보기 이미지.
- `validation.md`: YAML 구문과 브라우저 확인 결과.

YAML/CSS는 Figma의 기본 저장 포맷이 아닙니다. 이 파일들은 Figma의 FRAME/TEXT, Fill/Hug, 방향·여백·간격 개념을 기록하는 자체 디자인 명세입니다. Figma 파일에 직접 가져오는 동작은 제공하지 않습니다. 기존 Figma 파일은 수정하지 않았습니다.

상단에서 전체·로그인·메인·상세 화면을 선택합니다. 로그인은 폼 검사 후 메인으로 이동하는 시연입니다. 검색·과목 필터와 모임별 상세 선택이 동작합니다. 로그인과 신청의 실제 서버 처리는 없으며 계정 정보·신청 정보를 저장하지 않습니다.

글꼴은 Google Fonts의 Noto Sans KR을 사용하므로 온라인 연결 시 정확한 글꼴이 표시됩니다. 웹 서비스로 배포할 때 실제 인증·신청 API는 별도로 연결해야 합니다.

기존 목록의 세 종류 모임 정보를 재사용했습니다. 로그인 안내·모집 조건·모임 소개는 새 화면 설계용 예시 문구입니다. 넓은 화면에서는 세 화면을 비교하고 좁은 화면에서는 세로로 확인합니다.

하단 메뉴: 홈·스터디목록·내모임·마이 페이지는 URL 해시 링크로 이동합니다. 내모임·마이 페이지는 데이터 연결 전 안내 화면입니다. 기존 이미지들은 하단 메뉴 추가 전 시안입니다.
