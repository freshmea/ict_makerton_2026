        시간별 총평을 선택하면 해당 시간의 상태와 바로 전 시간과의 비교를 볼 수 있습니다.

        이 분석을 읽는 방법

        카메라 두 대의 기록을 하나의 10초 구간으로 합칩니다. 같은 사람이 두 번 계산되지 않으며, 중복으로 생략된 기록도 원래 내용과 최신 촬영 시각을 연결합니다.

        학습 행동 비율은 재석 표본에서 읽기·필기·키보드 입력이 보인 비율입니다. 자리비움은 관측된 표본 기준이며, 미수집·판단 불가는 별도로 표시합니다.

        감정은 관찰 문구·키워드의 추정 단서입니다. 직접 측정한 감정이나 로봇 눈 표정의 비율이 아닙니다. 서로 다른 단서가 함께 나오면 복합 단서로 분류합니다.

        예를 들어 미소·웃음은 긍정, 차분·평온은 차분, 긴장·초조는 어려움, 하품·피곤은 피로 단서입니다. 읽기·필기만으로 차분한 감정을 가정하지 않으며, 부정 표현은 단서에서 제외합니다.

        시간·하루·월 총평은 지표에서 자동 작성합니다. 진행 중인 기간은 이전 기간의 같은 경과 구간과 비교하고, 비교 자료가 없으면 평가를 보류합니다. 추가 AI 요청은 없습니다.
